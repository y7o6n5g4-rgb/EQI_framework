## §1. §35a 정식 등록 [S97 신규 §]

### 1.1 정의

```
§35a: §35 격자 브리지 [S97 신규, §35에서 파생된 응용 §]

X_i = (3-Δ_i)/D1_ELL
    = (pᵢ/qᵢ) + 잔류_i/D1_ELL        ← X_i 단위

여기서:
  Δ_i   = log_φ(D2_i/D1_i)
  D1_ELL = (1+GAP)/√[(1+GAP)²+φ⁶]   [§35 capillary 성분]
  (pᵢ/qᵢ) = 루카스 조합 (target)

단위 구분:
  잔류_i       = (잔류/LC²GD 값) × LC²GD   [절대량]
  잔류_i/D1_ELL = X_i의 잔류 부분             [X_i 단위]
  잔류/LC²GD   = 잔류를 LC²GD로 정규화         [LC²GD 단위]

물리 해석:
  "§35 기준선(D2/D1=φ³)에서 각 TZ 실측 비율까지의
   D1_ELL 단위 루카스 거리"
```

### 1.3 잔류 2차 구조 발견

```
[§88 잔류 2차 구조]  ★★★
  잔류/LC²GD = 2.082
  = 2 + 88×LC²GD     [LC²GD 단위]
  
  단위 환산:
    잔류 자체 (절대)    = 2.082 × LC²GD = 0.001940
    잔류/D1_ELL (X_i)  = 0.001940/D1_ELL = 0.008194
    
  (잔류/LC²GD - 2)/LC²GD = 88.005 ≈ 88
  88 = 2×L₃×L₅ = 2×4×11  [루카스 귀속]
  
  주석: §번호 자기 참조 가능성 병기

    잔류 자체 (절대)   = 2.945 × LC²GD = 0.002745
    잔류/D1_ELL (X_i) = 0.002745/D1_ELL = 0.011591
    
  3 = L₂ (루카스), 59 = §62 샤가프 AT비율 → §62 참조 구조

통합 형식:
  잔류/LC²GD = n_i ± m_i×LC²GD
  n_i: 루카스 정수 (2=비리얼, 3=L₂)
  m_i: §참조 계수 (88=자기 참조, 59=§62 AT)
```
