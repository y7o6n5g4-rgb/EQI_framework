## §2. S65 핵심 탐색 방향

### 2.1 최우선 — 키르히호프 법칙 D1/D2 포섭

```
KVL (전압 법칙) → D1:
  폐회로 전압합 = 0
  = 닫힌계 보존, 스칼라, 수렴
  → D1 귀속

KCL (전류 법칙) → D2:
  노드 전류합 = 0
  = 열린 노드 분기, 벡터, 발산
  → D2 귀속

KVL(D1) + KCL(D2) = Unity 구조 탐색
  = D1×D2 항등식 성립 여부 확인
```

```

  = 맥스웰 도깨비 작동
  = 변환 비용 = GAP_D2 추적

탐색:
```
