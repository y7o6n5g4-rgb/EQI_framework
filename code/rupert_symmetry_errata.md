  - 회전 인코딩에서 −d 는 그림자 좌표의 반사 (x, −y) 로 나타나므로, 두 그림자는 평면 등거리 (반사 포함) 로 합동이다.

  - 필터는 |d_in·(G d_out)| 의 최소각을 썼으므로 이미 d ↔ −d 를 동일시했다. 따라서 실제 동일시 집합은 {±g} = 올바른 집합과 같다.
  - 후보 선택 결과 (0개) 와 모든 기하 인증 결과는 바뀌지 않는다. 정정 대상은 "O_h = 물체 대칭" 이라는 서술뿐이다.
