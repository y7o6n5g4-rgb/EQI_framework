# 정정 메모 — 쌍대 실현가능성과 유계성 (2026-10-22)

대상 역사 문서는 덮어쓰지 않고 원본을 유지한다.
- `code/rupert_cert_verify_report.md` (커밋 `ba81fda`): §1 표 행 1c 의 괄호 "(O 유계 ⇔ 쌍대 실현가능)"
- `code/rupert_cert_verify.py` 출력 문구: "쌍대 실현가능 ⇔ 0 ∈ conv{n_j} ⇔ O 유계 …"

## 오류
"0 ∈ conv{n_j} ⇔ O 유계" 는 **틀리다**. 0 ∈ conv{n_j} 는 유계성보다 약한 조건이다.

반례: 법선이 n = (1,0), (−1,0) 뿐이고 b = (1,1) 이면 다음과 같다.
- 0 = ½n₁ + ½n₂ ∈ conv{n_j} 이다.
- 그러나 O = {|x| ≤ 1} 는 띠 모양이라 유계가 아니다.
- 그래도 평행이동 LP 의 최적값 M 은 유한하다 (I 가 한 점이면 M = 1).

## 정정된 문장
1. **비음수 균형 가중치 존재.** w ≥ 0, Σw = 1, Σw n_j = 0 인 w 가 존재 ⇔ 0 ∈ conv{n_j}. 볼록 껍질의 정의 그대로다.
2. **평행이동 LP.**
   - 원문제 max m s.t. n_j·τ + m ≤ g_j 는 항상 실현가능하다 (m → −∞).
   - LP 쌍대 정리에 따라 M 이 유한 ⇔ 쌍대 실현가능 ⇔ 0 ∈ conv{n_j}. 이때 M = min Σ w g 이다.
   - O 의 유계성은 필요하지 않다.
3. **양의 가중치 ≤ 3.** 쌍대 실현가능 (0 ∈ conv{n_j}) 이면 쌍대 실현가능 영역 {w ≥ 0, Σw = 1, Σwn = 0} 은 비어 있지 않은 유계 다면체다. 따라서 최적값이 꼭짓점 (기저해) 에서 도달되고, 기저해의 양의 성분은 3개 이하다. 역시 O 의 유계성은 필요하지 않다.
4. **유계성 (참고).** 비어 있지 않은 full-dimensional H-polytope O = {x : n_j·x ≤ b_j} ⊂ R² 에서 다음이 서로 동치다.
   - O 가 유계
   - 후퇴 원뿔 {d : n_j·d ≤ 0 ∀j} = {0}
   - 법선들이 R² 를 양의 일차결합으로 생성 (positive spanning)
   - 0 ∈ int conv{n_j}
   
   0 ∈ conv{n_j} (경계 포함) 만으로는 부족하다.
5. **영향 범위.** 기존 검증의 결론은 바뀌지 않는다. 증명서 부등식 M ≤ Σwg, 기준시험 A/B/C, 무작위 LP 시험 결과는 유계성 문구와 무관하다. 정정 대상은 조건 서술의 동치 관계뿐이다.
