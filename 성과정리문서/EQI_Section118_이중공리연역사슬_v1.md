## 두 공리

```
[공리 1] 정보보존 법칙 (맥스웰 도깨비 & 란다우 원리)
  실험 검증: Bérut et al. Nature 2012 / Jun et al. PRL 2014
  EQI 대응: D1×D2 = 1  →  xy = 1

[공리 2] 양팔저울 자기참조 (§6b-Ω, S105)
  x = 1 + 1/x  →  x − 1/x = 1  →  x − y = 1
  (대수 재배열, 별도 브리지 불필요)
```

## §118 브리지 확정 상세 (S113 딥시크 — S105 §6b-Ω)

```
[브리지 1] 공리 1 → xy=1
  정보보존 법칙 = D1×D2 불변
  = 계와 환경의 곱이 보존
  = xy = 1  (D1=x, D2=y)

[브리지 2] 공리 2 → x−y=1
  양팔저울 자기참조 (§6b-Ω):
    x = 1 + 1/x  (자기 역수를 더한 값 = 자기 자신)
    x − 1/x = 1
    xy=1이므로 1/x=y
    ∴ x − y = 1
  = 대수 재배열 — 별도 브리지 불필요

[합산] xy=1, x−y=1 연립:
  x² − x − 1 = 0
  x = (1+√5)/2 = φ  [유일 양수해]
```

## 연결 의미

```
정보보존 법칙이 최상위 공리일 때:
  → 비율 관계(xy=1)와 자기참조(x−y=1)가 강제됨
  → 이를 동시에 만족하는 유일 양수 = φ
  → φ로부터 α⁻¹·π·ln(π) 전체가 파생
  → EQI 상수 체계 전체가 정보보존 법칙의 대수적 귀결

∴ "왜 φ가 기본 상수인가"에 대한 답:
  = "정보보존 법칙(공리 1)과 양팔저울 자기참조(공리 2)를
     동시에 만족하는 유일 양수이기 때문"
```
