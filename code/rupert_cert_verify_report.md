## 2. 발견한 반례·수정식

### 2.1 거의 균형인 가중치 (제안 1e)
- 설정: O = [−1,0]×[−1,1], I = {원점}, g = (0,1,1,1), 법선 (±1,0), (0,±1). 진짜 M = 0.5 (τ* = (−0.5, ·)).
- w = (½+ε, ½−ε, 0, 0), ε = 1e-6: Σw = 1 이지만 Σwn = (2e-6, 0).
- Σw g = 0.499999 < M = 0.5 → "M ≤ Σwg" 주장이 **거짓**.
- 수정식: w ≥ 0, s = Σw > 0, r = Σwn 이면 ‖τ‖ ≤ T 인 모든 τ 에 대해 m ≤ (Σwg + T‖r‖)/s.
  엄격 통과는 I+τ ⊂ O 를 요구하므로 T = R_O + R_I (원점 기준 외접 반지름 합) 로 제한 가능.
  (Σwg + T‖r‖)/s ≤ 0 이면 이 투영 쌍의 엄격 통과 없음. 반례에 적용: 0.500001828 ≥ M (모순 없음).
- 인증 조건: s, r, Σwg 계산 자체를 구간 산술 또는 정확 산술로 수행해야 함.

### 2.2 R²−q² 의 부동소수점 (제안 2c)
- v = (0.7, 0.1, 0.2), n = v/‖v‖: float R²−q² = −1.11e-16 → sqrt 는 NaN.
- v = (0.1, 0.2, 0.3): R²−q² = +2.78e-17 → p = 5.27e-9. 참값은 0이므로 √ε 크기의 가짜 값.
- 수정: p = ‖n × v‖. 이렇게 하면 두 경우 모두 0.0이 나옴. 또는 p = sqrt(max(0, R²−q²)).

### 2.3 Euler 각 합의 적용 조건 (제안 2e)
- d(A,B) = ∠(AᵀB) 는 SO(3) 의 양측 불변 거리.
  R(a) = R_1(a_1)···R_k(a_k) 이면 d(R(a), R(b)) ≤ Σ_i min(|Δa_i| mod 2π, 2π − …) (삼각부등식 + 불변성).
- 조건:
  - (i) 각 인수가 고정 축 둘레의 '각도 = 회전각' 축 회전 (스케일 없음)
  - (ii) 곱 형태로 쓸 수 있을 것
  - (iii) 합 > π 이면 ρ = π 로 절단 (정보 없음)
  - (iv) v 는 회전 중심 기준 좌표, 평행이동 τ 는 별도
- 구면 좌표 (θ, φ) 를 Rz(φ)Ry(θ) 곱으로 쓰면 성립한다. 이때 φ 의 실제 변위는 sinθ 배로 더 작으므로 상계는 보수적이다.
- [float] Rz·Ry·Rz 무작위 2000쌍: 위반 0건, 최대 비 (각/Σ|Δ|) = 0.9915.
- 추가 조건: 바깥 투영이 회전하면 O 의 법선 n_j 와 b_j 도 함께 변한다.
  U/L 은 '고정 단위 방향 n 에 대한 내적' 경계이므로, 칸 전체 증명에 쓰려면 O 쪽 변화도 별도로 묶어야 한다.
  안쪽 지지값 h_I(n) 는 U/L 로 바로 묶인다 (불통과 증명 시 h_I ≥ max_v L_v).

## 3. 정육면체 기준시험 원시 수치

- 바깥 그림자 [기호]: 꼭짓점 (±√2, ±√6/3), (0, ±2√6/3).
  √6/3 = √(2/3), 2√6/3 = √(8/3) 이므로 제안 좌표와 **일치**한다 (원점에 투영되는 2점은 제외).
- 정육각형 6변 법선 0°, 60°, …, 300°, b_j = √2 (모두 정확, 내접 반지름).
- λ0 = 2√2/(1+√3) = √6 − √2 = 1.03527618041008304939559535050

- C 의 보증 논리 [기호]:
  - |θ| ≤ π/360 에서 (cos(π/3−θ), sin(π/3−θ)) 두 성분은 모두 양수이고, 지지 꼭짓점은 (1,1) 회전상이다.
  - 7π/12 − θ ∈ [104.5°, 105.5°] ⊂ (90°, 180°) 에서 sin 은 단조감소한다. 따라서 Σwg 최댓값은 θ = −π/360 끝점에서 나오고, 그 값은 음수다.
  - 구간 산술 (64등분) 로도 독립 확인했다. 여기서 쓴 회전 볼 하계 (ρ = π/360) 는 이 1차원 경우에 정확한 값과 일치한다.
- 범위 주의:
  - C 는 '이 투영 쌍 + 안쪽 평면 회전 1차원 구간 + λ = 26/25' 에서의 불가능성만 보증한다.
  - 정육면체 전체의 비루퍼트 판정이 **아니다**. 정육면체는 루퍼트이며 ν = 3√2/4 > λ0 이다.
  - λ0 는 이 투영 쌍의 값이며, 정육면체 전체의 최적값이 아니다.
  - 각도 간격 π/360 은 단위시험용이며 EQI 격자 규칙이 아니다.
