## A. θ = 0 별도 보조정리
- θ = 0 이면 안쪽 그림자와 바깥 그림자가 같은 다각형 O 다.
- 검증기 확인 사항:
  - Q 전체에서 O 는 꼭짓점 순서 (2,3,1,0,7) 의 볼록 오각형이다.
  - 신발끈 면적 구간은 [3.70105899, 3.72742970] 로 양수다.
- 증명 (모든 τ):
  - τ = 0: O 의 경계점은 int(O) 에 속하지 않는다. 따라서 O ⊄ int(O).
  - τ ≠ 0: x* = argmax_{x∈O} τ·x 로 두면 τ·(x*+τ) = max_O τ·x + |τ|² 이다. 따라서 x*+τ ∉ O 이고 O+τ ⊄ int(O).
- LP 관점에서 g_j = 0 (기호) 이고 양수 w* 로 m ≤ 0 이며, τ = 0 에서 m = 0 이다. 그래서 M(0) = 0 이다.
  - **B(0) = 0 을 음수로 바꾸지 않았다.** θ = 0 은 이 보조정리로 처리하고, θ > 0 의 인증 (B < 0) 과 결합한다.

## C. 독립 재검증기
- **구현 분리**:
  - mpmath/numpy/scipy 를 쓰지 않는다. 유리수 구간 클래스를 직접 구현했다.
  - cos/sin 은 유리점 교대급수와 잘림 오차 상계로 감싼다. 구간이 (0, 3/2) ⊂ (0, π/2) 안에 있으므로 단조성으로 끝점에서 감쌀 수 있다.
  - R_out 은 닫힌 꼴로 독립 전개했다. 직교성 정합도 검사한다.
  - 균형 해는 **Cramer 명시식** 으로 구한다. 생성기의 iv.det/iv.lu_solve 경로와 다르다.
- **증명서에서 읽는 것**: 정의 입력만 읽는다 (형상, Q, 인수 순서, 오각형 순서, 쌍대 꼭짓점 변 번호, 증명서 정의, 칸 끝점·칸별 선택 증명서).
  - 생성기의 수치 결과 (a, b, δ, w 구간) 는 판정에 쓰지 않는다. [8] 대조 정보로만 표시한다.
- **단계** (하나라도 미확정이면 즉시 FAIL/UNKNOWN 종료):
  1. t_shape·꼭짓점을 정의에서 재생성해 일치 확인. Q 끝점이 q0 ± 1/1024 인지 확인. 인수 순서 확인.
  2. Q 전체 접촉 구조: 각 반시계 변에 대해 나머지 6 꼭짓점의 외적 하한이 > 0 이다 (최소 0.00628034).
  3. θ = 0 보조정리 (면적 > 0).
  4. Cramer: det 이 0 을 배제하고 (11.17…, 6.13…, 11.88…), w 하한 > 0, s′ 하한 > 0 (1.9107, 0.1840, 2.0051).
  5. 증명서 24개를 정의에서 재구성. 접촉이 변 양 끝인지, 24개가 서로 다른지 확인.
  6. 구면 피복: 면마다 칸이 [−1,1]² 안에 있고, 내부가 서로소이며, **정확 면적 합 = 4** 다. 따라서 닫힌 합집합이 정사각형 전체다. 6면 정규화 상은 S² 다.
  7. 96칸마다 선택 증명서의 a·b 를 재계산: min a ≥ 0.060272491827436 > 0, max b ≤ 1.795122201683, 자체 δ 하한 0.0603607146887, 모든 칸에서 a_lo ≥ b_hi/20.

## D. 결과 표기
- **정리**: P_{11/20} 의 지정한 바깥 방향 이웃 Q = (2/5, 9/10) ± 1/1024 (R_out(q) = Ry(−q1)Rz(−q2)) 에서, 모든 상대 회전축과 0 ≤ θ ≤ δ_safe = 1/20 에 대해 엄격한 투영 포함이 불가능하다.
