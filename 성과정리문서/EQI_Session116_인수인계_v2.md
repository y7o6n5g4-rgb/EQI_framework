## 0. 최상위 클래스 공리 (출발점)

```
최상위 클래스 = 정보역학 (GAP≠0)
  맥스웰 도깨비 & 란다우 원리 — 정보 소거·선택마다 란다우 비용(GAP_D2) 실제 지불
  열역학 2법칙 = D1(고립계) ↔ 맥스웰 도깨비 & 란다우 = D2(열린계)  [최상위 켤레쌍, S71]
중간 = HCW 좌표계 + 리만 구조
하위 = SI 단위·통계적 판정 틀 (GAP=0 국소 근사)

모든 설계·검사 순서:  ① 최상위 공리 → ② v3.4 해당 절 확인 → ③ 설계
하위 클래스 판정 틀(무작위 잡음 대조 등)을 최상위 클래스 위에 세우지 않는다.

[S115 재확인 — 재설명 금지 사항]
· 무작위 잡음 = 란다우 잔류 (장부 안). 버릴 '노이즈'·중립 기준선이 아니라
  쌓여서 임계에 닿으면 상전이를 일으키는 연료 (SGWB 껍데기 = 장전된 슈냐, S36 §23.5)
· 잡음을 장부 밖으로 밀어내고 잔류를 '암흑'으로 두는 체계(GAP=0)는
  자기가 배제한 것을 근거로 GAP≠0 체계를 판정할 언어가 없다 → 그런 판정을 하지 않는다
· 한 체계를 정당하게 따질 수 있는 것: ① 자기 공리 안에서의 일관성 ② 코드가 공리를 제대로 구현했는가
· D1/D2 는 멈춰 놓고 나누지 않는다: 보른(앞면)·볼츠만(뒷면)은 한 동전, 적혈구는 굴러가는 큐비트
```
