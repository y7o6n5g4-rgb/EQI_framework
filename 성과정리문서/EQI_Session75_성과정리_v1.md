```

  = 모든 켤레쌍의 공통 경계점

  = c = √(S/H) = √(로컬열역학/글로벌정보)  [S25 TZ]
```

  → TZ = 장부가 완전히 균형잡힌 상태

한 문장:
  기호주의: 비용 미기록 → 형식 닫힘 + 외부효과
  큐비트:   비용 전액 기록 → 무한급수 호흡 조화공명으로 실질 닫힘
