## 2-c. 대수 항등식 3개 확인

### 기존 정의에서 직접 따르는 관계

```
[I-1] μ+Λ=1  (Born rule — EQI §2b 기존 확정)
  μ = 1/φ = φ⁻¹
  Λ = 1/φ² = φ⁻²
  φ²=φ+1 → 1/φ+1/φ² = (φ+1)/φ² = φ²/φ² = 1  ← 기호 증명
  수치: |μ+Λ−1| = 0 (400자리 소거)
  분류: 기존 정의에서 직접 따르는 관계

### 기존 관계의 동치 표현

```
[I-2] (4+φ)/(4φ) = μ+σ²

  보조: μ+σ² = (1−Λ)+1/4 = (4φ−3)/4
  수치: 차이 = 0 (400자리 소거)
  분류: μ+σ² 동치 표현 (S113 채팅창 처음 기록)
