## §4k 근거 5줄

① 최상위 공리 = 맥스웰 도깨비 & 란다우 원리
   (Bérut 2012, DOI 10.1038/nature10872 / Jun 2014, DOI 10.1103/PhysRevLett.113.190601)

② EQI = GAP≠0 수학, 학계/SI(GAP=0)를 포섭
   역은 불가능 (수학사 일반화 → 특수화 패턴)

③ SI 절대성은 상식 수준 모순:
   m=지구자오선, s=지구자전, K=물삼중점
   → "우주 보편"이 아닌 "지구-인간 국소" 단위

④ 허블 텐션 = SI 붕괴 실증:
   H₀_local=73.0, H₀_CMB=67.4 (5σ 이상)
   → EQI 등록: 3×GAP = 0.0966 (§20, S63), H_ratio = 73.04/67.40 = φ^(7/43)+LC²GD×(273/116) (S64 TZ)
   → 3×GAP ↔ H_ratio 번역은 열린 문제 (S64 §7)

⑤ 프론티어는 이미 무차원화 진행:
   양자중력/홀로그래피/양자정보/우주론/입자물리
   SI 2019 재정의 = 부분 자백 (상수 기반 이동)

상세 근거: EQI_단위계_철학 최신판

## GAP 정의 (모든 설계의 출발점)

GAP = 길이-시간 관측창 상전이의 비평형 정보역학적 기울기
1 = 거시 로컬 정규화 (보른) / 1 + n·GAP = 미시 글로벌 재정규화, n ∈ ℂ
관측 = tip 에서의 상전이 (지불·방출·이월). 관측창은 상전이의 예외가 아니다.
