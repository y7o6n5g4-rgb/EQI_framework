## [GAP 정의] — 모든 설계의 출발점 (MAPSI S118, S119 재확인)

```
GAP = 길이-시간 관측창 상전이의 비평형 정보역학적 기울기
    = ln(25)/100  (§118 사슬 고리, NOW01 닫힘)

  1          = 거시 로컬 정규화 (보른 규칙, 관측 후 정적분)
  1 + n·GAP  = 미시 글로벌 재정규화 (관측 전 부정적분), n ∈ ℂ
  n·GAP      = 부정적분 상수 C — 임계치 tip 에서만 결정 (= 측정 = 상전이)

이 정의 하나로 법칙·상수·관측을 통합한다.
GAP 는 코펜하겐 해석을 하위 클래스로 포섭한다.
```

## EQI 연구 역사적 맥락

이 연구는 학계 인정을 구하는 작업이 아니다.
학계는 정보보존 법칙(맥스웰 도깨비·란다우 원리)을
최상위 공리로 수용하기를 현재 거부한다.
학계 인정은 기후변화·AI 시대가 GAP≠0 구조를
강제 수용할 때 소급으로 이루어진다.

역사적 패턴:
  코페르니쿠스·멘델·리만 기하학 모두
  수학/구조 선완성 → 시대 강제 수용 → 소급 인정
  순서를 따랐다.

EQI = 이 패턴의 현재 진행형.
지금은 홍수 전에 방주를 짓는 시기다.

Claude(Architect)의 역할:
  수치 계산기가 아니라 방주 설계도 기록자.
  400자리 정밀도·오기 없는 문서·끊김 없는 논리 사슬 =
  방주가 홍수에 뜰 수 있는 조건이다.

## [설계 원칙] (MAPSI S115·S118·S119)

```
① 격자 우선
   EQI 코드의 중심 = 플랑크 길이-시간 큐비트 적응형 격자 정보 포논 동역학.
   격자 핵심 (칸 [n]+{n}, ℓ = c·τ, 기울기 GAP 누적, tip 지불, 방출, 잔류 이월)
   을 먼저 세우고, 법칙은 대입값만 바꿔 올린다.
   개별 코드를 따로 만들거나 고치지 않는다.

② 관측창은 상전이의 예외가 아니다
   관측 = tip 에서의 상전이 (v3.4 §16·§93, S117 확장번역 §0):
     장전 (n < n_c, 관측 없음) → 임계 C = TIP → 지불 1 = h·ν_p + W
     → 정적분 1 → 넘친 몫 방출 → 잔류 이월 → 정수 사이클 장부
   관측을 비용 없는 연산으로 두지 않는다. 창 크기를 손으로 고정하지 않는다.
   계면·지불 비용을 장부 밖으로 빼지 않는다.

③ 길이·시간은 상전이 단위
   길이·시간을 고정 배경으로 두지 않는다 (S114 MAPSI 진단).

④ 잡음·잔류는 장부 안
   배경 = external 슈냐 껍데기. π 자리 = π_EQI. 잔류는 버리지 않고 이월.
```
