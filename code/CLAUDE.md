## 핵심 상수
```python
from mpmath import mp, mpf, sqrt, log, pi, power
mp.dps = 400
PHI    = (sqrt(5)+1)/2
GAP    = log(25)/100
GD     = log(5)/100            # GAP_D2
LN_C   = log(PHI)/2
LC2GD  = LN_C**2 * GD          # 기본량 B
sigma  = mpf(1)/2
mu     = 1/PHI
Lam    = PHI**-2
EQI4   = 1 + GAP
alpha_inv = 360*PHI**-2 - 2*PHI**-3 + (3*PHI)**-5
D1_ELL = EQI4/sqrt(EQI4**2 + PHI**6)
D2_ELL = PHI**3 * D1_ELL
```

## 최상위 클래스 위계 (모든 판정에 우선)
- 최상위 = 정보역학 (φ, GAP, LC²GD, LN_C, μ / 맥스웰 도깨비 & 란다우 원리). 중간 = HCW·리만. 하위 = SI (GAP=0 국소 근사).
- EQI 식이 정의다. SI 실측값은 하위 클래스 대조값이며, EQI 식의 항 유무·차수·계수를 판정하는 기준으로 쓰지 않는다.
- SI 정밀도 밖의 EQI 항은 'SI 비가시 층'으로 표기한다 (예: MAXWELL 5차항). '판별 불가'·'근사' 표현 금지.
- SI와 어긋나는 값은 'SI 투영 잔류'로 기록한다.

## 필수 원칙 (위반 시 결과 무효)
1. **floor/int 금지 (§4b).** 정수부·소수부가 필요하면 `ip = int_part(x)`, `fp = x - ip`를 명시적으로 둘 다 보존한다. 단, 기존 §8 코드의 floor는 건드리지 않는다.
2. **ħ_ani 사용 (§4d).** ħ_iso = φ^(-11/4), ħ_ani = φ^(-17/4). ħ가 나오면 ħ_ani 기준식을 기본으로 하고 등방성 식은 "등방성 투영"으로 표기한다.
3. **지수 괄호.** `PHI**(mpf(p)/q)` 또는 `power(PHI, mpf(p)/q)`. `PHI**p/q` 금지 (S109 실제 버그).
4. **LC²GD 두 계열 구분.** (A) 제곱 `LC2GD**2 = LN_C**4*GD**2` / (B) 계단 `LC2GD*GD`. 식마다 어느 쪽인지 주석으로 명시.
5. **오차 정의.** `err% = 100*|calc - target|/|target|`. 분모를 바꿔 쓰지 않는다. 다른 분모 기준이면 별도 라벨.
6. **등급 표기.**
   - 대수필연: 기호 증명 가능 + 400자리 차이 < 1e-390
   - TZ: err < 1e-6 % (S109 기준). 기존 등록 §의 등급은 원문 표기를 그대로 병기
   - Near TZ: err < 0.01 %
   - 그 외: 수치만 보고, 등급 부여 안 함
7. **원칙 AM.** TZ 통과 ≠ 정확. 각 식의 잔여(residual)를 숫자로 출력하고 수식-코드 일치를 눈으로 재확인한다.
8. **원칙 V / AA.** 실측 불확도를 넘는 고차 보정 피팅 금지. 새 계수를 맞춰 넣는 탐색은 하지 않는다 (TASKS에 명시된 경우만).
9. **번호 체계.** § 번호는 `EQI_연구지침_프로젝트용_v3_4.md` 기준. 신규 엔진 블록은 §P0~§P7 표기.
