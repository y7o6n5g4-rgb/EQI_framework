## 설정
- 물체: P_{11/20} (정확 유리수 꼭짓점).
- 바깥 회전 R_out = Ry(−2/5)Rz(−9/10) 로 고정한다. 바깥 그림자는 오각형이고, 꼭짓점 반시계 순서는 (2, 3, 1, 0, 7) 이다.
- 안쪽 회전 R_in = R_out·exp(θ[u]×) 이며, u 는 단위구면 전체를 돈다.
  - θ > 0 만 다루면 충분하다 (−θ 는 축 −u 와 같다).
- θ = 0 접촉 동률의 정확 처리:
  - 모든 변에서 나머지 꼭짓점이 엄격 내부에 있음을 구간으로 인증했다.
  - 따라서 θ = 0 의 접촉 집합 S_j 는 정확히 변의 양 끝 꼭짓점 2개다.
  - 동률은 아래 B 에서 두 꼭짓점을 모두 증명서 후보로 넣어 처리한다.

## A. 정확 균형의 보장 방식
- **구분**: "구간 잔차가 0 을 포함" 하는 것과 "정확해가 Σw n = 0 을 만족" 하는 것은 다르다. 앞의 사실로는 r = 0 을 주장할 수 없다.
- **방법**:
  - 변 3개 조합마다 3×3 연립식 [1,1,1; n_x; n_y]·w = (1, 0, 0) 을 세운다. n_j 는 정확 비정규화 법선이다.
  - 구간 행렬식이 0 을 배제하면 정확해 w* 가 존재하고 유일하다.
  - 구간 LU 해는 w* 를 포함한다. 각 성분의 구간 하한이 0 보다 크면 w* > 0 이다.
  - w* 는 행 2·3, 즉 Σw n = 0 의 정확해다. 이것이 r = 0 의 근거다.
  - 재계산 잔차 구간 (±5e−30) 이 0 을 포함하는 것은 정합성 점검일 뿐 논거가 아니다.
- **결과**: 10개 조합 중 3개가 정확 균형 쌍대 꼭짓점이다. 나머지는 해의 부호가 비양수이거나 미확정이라 제외했다.

- **s′ 환산**: 비정규화 법선의 쌍대식은 M_unit 기준으로 M·Σw|n_j| ≤ Σw g_j 다. 따라서 단위 법선 기준 기울기는 a/s′ 다.
  - B 의 부호는 s′ > 0 이므로 바뀌지 않는다.

## B. 유한 증명서 집합
- 증명서 = (정확 균형 쌍대 꼭짓점 J) × (J 의 세 변마다 접촉 꼭짓점 2개 중 하나 선택) 이다.
  - 3 × 2³ = **24개**.
- 고정 꼭짓점 v_j 의 내적은 h_I 의 하계다. 따라서 Rodrigues 정확 항등식으로 다음이 성립한다.
  - B(θ)/s′ ≤ Σw_j [b_j − ν_j·R_out e^{θ[u]×} v_j]/s′ = −sinθ·â_k(u) + (1−cosθ)·b̂_k(u).
- 계수 정의:
  - â_k(u) = d̂_k·u. 여기서 d_k = Σ w_j (v_j × R_outᵀν_j), d̂_k = d_k/s′ 이다.
    - 근거 항등식: ν·R(u×v) = (Rᵀν)·(u×v) = u·(v × Rᵀν).
  - b̂_k(u) = Σ w_j [v_j·ν′_j − (u·v_j)(u·ν′_j)]/s′, ν′_j = R_outᵀν_j.
- 실제 지지 꼭짓점이 경로 위에서 바뀌어도 이 상계는 유효하다. 전환은 h_I 를 키워 B 를 낮출 뿐이다.
- 따라서 임의의 증명서 k 하나가 그 축에서 â_k > 0 이면 충분하다.
  - 축마다 최선의 k 를 골라도 된다 (각 k 가 독립적으로 유효한 상계이므로).
- **회귀 (기존 여섯 경로)**: max_k d̂_k·u 와 `rupert_local_ineq` (9a77ac0) 의 a/s′ 를 비교했다.

## C. 모든 단위축에서의 일차 하한 — D = conv{d̂_k}
- **float 구조 (비인증)**:
  - D 의 꼭짓점은 17/24 개, 면은 30개다. 원점은 내부에 있다.
  - min_u max_k d̂_k·u ≈ 원점-면 최소거리 = 0.199461912961 이다.
  - 최약 방향은 u* ≈ (−0.767448, −0.275750, 0.578780) 이다.
- **구간 인증**:
  - 정육면체-구면 매개 6면 × 4×4 = 96 칸으로 나눈다. 칸의 구간 벡터는 정규화된 u 를 모두 포함한다.
  - 각 칸에서 lo(d̂_k·U) 가 가장 큰 k 를 고르고, 하한 > 0 이면 인증한다. 실패 칸은 최대 깊이 7 까지 4분할하도록 했다.
  - 결과: **96칸 모두 깊이 0 에서 인증, 실패 0**.
  - ⇒ 모든 단위축 u 에서 max_k d̂_k·u ≥ **a0_cert = 0.094877909200231 > 0** 이다.
  - 사용된 증명서는 15개다 (출력 파일에 목록이 있다).
  - a0_cert 는 칸 크기만큼 보수적이다. 실제 하한 (float 추정 0.1995) 보다 작다.

## D. 이차항 상계와 δ
- **균일 상계**:
  - |v·ν′ − (u·v)(u·ν′)| = |ν′·(u×(u×v))| ≤ ‖ν′‖‖v‖ 이다.
  - 따라서 b̂_k(u) ≤ Σw_j‖ν′_j‖‖v_j‖/s′ 이고, 증명서 전체 최대는 **bmax = 1.73205080757** (= √3; 접촉 꼭짓점 노름 √3, ‖ν′_j‖ = |n_j|) 이다.
- **칸별 상계**: 각 칸에서 사용한 증명서의 b̂_k(U) 구간 상한을 쓴다. 최대 1.77339753244 다 (구간 과대평가로 균일값보다 약간 크다).
- **δ 논증 (독립 확인)**:
  - θ ∈ (0, 1] 에서 sinθ ≥ θ − θ³/6 ≥ 5θ/6 (θ² ≤ 1) 이고, 1−cosθ ≤ θ²/2 이다.
  - â ≥ a > 0, b̂ ≤ b 이면 B/s′ ≤ −(5/6)aθ + (1/2)max(b,0)θ² 이다.
  - 이 값은 0 < θ < (5/3)a/b 에서 음수다.
  - δ = min(1, a/b) 는 그 안쪽이다. b ≤ 0 이면 δ = 1 이다.
  - 제안된 δ 공식이 유효함을 확인했다.
- **결과**:
  - 균일 δ = min(1, a0_cert/bmax) = **0.0547777864169**
  - 칸별 δ = min_칸 min(1, a_칸/b_칸) = **0.0656753763868**
  - 두 값 모두 유효하다. 큰 쪽을 채택한다: **δ = 0.0656753763868**.
- **증명된 범위**:
  - 고정 바깥 배치 하나 (R_out 고정, t_shape = 11/20) 에서 모든 단위축 u 와 0 < θ ≤ 0.06567537 에 대해 B < 0 이다.
  - 즉 안쪽 상대 회전 배치의 엄격 포함이 배제된다.
  - 기존 여섯 경로 증명 (δ = 1) 보다 범위는 좁다. 대신 모든 축을 덮는다.
- **독립 float 점검 (비인증, 스크래치)**:
  - 무작위 축 4000개 × θ ∈ {δ, δ/3, δ/30, 1e−4} 에서 실제 LP M 을 계산했다.
  - max M/θ = −0.2115 < 0 이다. 인증 결과와 모순이 없다.
