## 2. 확정 구조

### 2.1 출발점 정정 (MAPSI S119)

확률·통계 법칙의 비율 1 = 보른 규칙 |ψ|² = 1 (거시/로컬, D1 승격 자리, 관측 후 정적분 1). 아키텍트 초안은 볼츠만 점유 p0 + p1 = 1 에서 ψ 를 거꾸로 만들었으나 (역방향), MAPSI 지적으로 전방 연역으로 바로잡음. 볼츠만 확률은 출발점이 아니라 파이프라인 끝에서 재현되는 대상.

### 2.2 노름 장부 `born_to_global()` (v2.9, BG 묶음)

| 기호 | 정의 | 자리 |
|---|---|---|
| B_loc | \|ψ0\|² = FERMAT = 1 | 거시/로컬 보른, 정적분 |
| C(n) | n·TRANSFER = n·(FEYNMAN − FERMAT) = n·GAP | 미시/글로벌 열린 몫, 일 장부 |
| Z(n) | B_loc + B_loc·C(n) = 1 + n·GAP | 재정규화 |
| 리프트 / 관측 | √Z / 1/√Z | 부정적분 ↔ 정적분 |

접점 n = 0: Z = 1 = μ + Λ. n = 1: Z = FEYNMAN. tip: C(n_c) = TIP. 복소 n: 진폭 장부 |Z_pol| 와 위상 장부 n_im·IG 분리.

### 2.3 두 쌍의 구별 (v2.9, PR 묶음, MAPSI §118 지적)

| 쌍 | 성립식 | 단계 |
|---|---|---|
| seed 성분쌍 (a, b), a = tanh φ⁻² | a² + b² = 1 (보른 제곱합). a·b = 0.33936 ≠ 1 | ①② |
| 켤레쌍 (Z, p0) | 공리 1 xy = 1 (모든 n), 공리 2 x − y = 1 (n = μ/GAP 한 점) | ③ |

PS-8 은 계산 근거 (정의 p0 = 1/Z) 와 §118 공리상 역할 (공리 1 켤레쌍) 을 따로 적는다. μ/GAP 점은 B21 후보 (등록 승인 대기).

## 3. 법칙별 결과

### 3.1 볼츠만 (v2.8~2.9)
- 9개 특수점에서 리프트 |√Z·ψ0|² = Z(n), 관측 몫 p0 = 1/Z 가 v2.7 state 와 일치
- BZ-3~9 와 B18 We 점 p0 = St 가 파이프라인 끝에서 재현
- perplexity JSON 6점과 자릿수 끝 수준 일치

### 3.2 란다우어 (v2.10)
- [고정 K0] 장부 (C·I·D 는 K0 단위 수) 와 [확장 K(n)] 장부 (K0·Z, 1비트 하한 K·ln 2) 분리 유지
- 볼츠만 연결: I = ln|Ψ|² = −ln p0. 1비트 점 p0 = σ → I = ln 2, C = 1, D = 1 − ln 2
- LD-1~8 전부 재현, LD-7 대수 극한과 Jun 2014 해석 (I) 분리 유지

### 3.3 흑체 = 보스 통계 (v2.11, 신규)
- [설계 배치] n̄ = C(n) = n·GAP → 보스 분배함수 Z_B = 1/(1 − q) = 1 + n̄ = Z(n)
- 배치 귀결: q = e^(−x) = 볼츠만 p1, P(0) = p0
- 보른 Σ P(k) = 1, Σ qᵏ = Z, ⟨k⟩ = n̄ 를 무한급수로 검산 (tip 1402 항, 1비트 1346 항)
- S116 §14 세 점 재현: x = ln φ ↔ n = φ/GAP (n̄ = φ, (n̄+1)/n̄ = 1 + 1/φ 공리 2), x = 3 ln φ ↔ n = σμ/GAP, x = 1 ↔ n = 1/((e_EQI − 1)·GAP)
- 페르미 §18-E 전부 재현, η(s)/ζ(s) = 1 − σ^(s−1) (3/4, 7/8)
- 슈테판-볼츠만 지수 −7/4 (CUR05 현행), σ_SB(EQI) = 17.577606164452556725 (π_EQI §90a 고정점, 상한 400 중 64 회)

### 3.4 훅 (v2.12, 2차 결정론 첫 법칙)
- [설계 배치] 결정론 법칙 = n = 0 자리 (Z = 1). 사이클이 열리면 Z_s = −Z(n), Im I = π
- [설계 배치] 진동자 = 보스 모드 → ⟨x²⟩(n) = ħ_ani·(n̄ + σ), ⟨E⟩(n) = ħ_iso·ω_p·(n̄ + σ)
- S24 세트에서 ħ_iso/(M_p·ω_p) = ħ_ani, k_B·T°/(ħ_iso·ω_p) = 1 → T° 는 흑체 x = 1 점에 놓임
- 영점 ⟨x²⟩ = σ·ħ_ani, ⟨E⟩ = σ·m_g, 비리얼 U/⟨E⟩ = σ
- S117 §24 기등록 7 항목 전부 재현 (F_p = φ², k_p = We = G, U(L_p)/E_p = σ, 등분배 ħ_ani, St, 두 플랑크 힘 간극 We)

## 6. 구현 범위 (perplexity S119 요청, 모든 판 공통)

- 위상 = 별도 장부. θ_seed, θ_cycle, 부호 위상 π 를 기록만 하고 진폭 장부 (점유·비용·⟨x²⟩) 에 합치지 않는다. 위상이 비용에 들어가는 방식은 정하지 않았다.
- 격자 = 알려진 경계 (1비트, tip, n̄ = φ, n̄ = σ) 의 membrane_split 세분 절차 검산. 독립 발견이 아니며 사이클 n 과 실제 시간 τ 를 동일시하지 않는다. 막 소거 장부는 법칙 장부와 합산하지 않는다.

### 6.1 ★ 원칙 미적용 판정 (MAPSI 지적, S119 말미)

LIGO v2.3 설계서 v4 §0 ② "길이·시간 = 상전이 단위, 창 길이 = 층의 시간-대역 곱으로 결정 (고정 창 없음)" 과 §2.4 "계면 세포막 비용 {x}·GAP_D2² 를 층 분해 총 비용에 합산" 기준으로 대조한 결과, S119 코드 (v2.8~v2.12.1) 는 **관측창을 상전이의 예외로 두었다**.

| # | 자리 | 내용 |
|---|---|---|
| W-1 | 관측 단계 (BG-6, PS-4) | 관측 = 1/√Z 를 곱하는 무손실 왕복 (잔차 0 을 PASS 로 검산). 관측창 개폐에서 GAP·란다우 비용·잔류가 없음 |
| W-2 | membrane_split 구간 | [0, 34], [0, n_k5] 를 손으로 고정. 창 크기가 상전이 규칙에서 결정되지 않음 |
| W-3 | 막 소거 장부 | "법칙 장부와 합산하지 않음" 으로 계면 비용을 장부 밖으로 뺌 |
| W-4 | ⑤ 길이·시간 | length_from_time (ℓ = c·τ), lattice_normalize 미사용. "n ≠ τ" 문구로 시간을 배경처럼 남김 |

**영역별 유효 범위 (MAPSI 지적 — 관측창 ↔ 7체)**

| 영역 (사이클 축) | S119 점 | 상태 |
|---|---|---|
| 5체 영역 (n < 62.58) | σμ/GAP 9.60, T° 18.08, μ/GAP 19.20, 1/GAP 31.07, tip 32.87, k=2~5 껍질, φ/GAP 50.27 | 대수 PASS 유효. W-1 은 tip 지불로 보정하는 범위 |
| 7체 경계 | TH_D1 껍질 62.58, X7 63.10 | 다루지 않음 |
| X7 너머 | We 도달 85.62 (BZψ-We, B18 p0 = St, LA·BB·HKL 표 We 줄), θ_L 점 100.53 (BZ-9, BZψ-9), (We − σ)/GAP 101.15 (HKL) | 대수 PASS 는 나왔으나 관측창이 해상도 한계 (φ^(−7.5) < GAP < φ^(−6.5)) 를 넘은 영역 — **미검증**. phonon_order 가 k = 5 에서 멈춰 X7 통과가 장부에 나타나지 않음 (아키텍트 누락) |

확장 번역 (B18 We 계면 포함) 은 5체 닫힘 (S62) 과 7체 §21 [S]·[T] 계열 위에 있으며, 7체 고유 고리인 §21 [R] We·TH_D1/양성자/Ro = 1 (S63 등록, 물리 귀속: 핵력, TH = 종파↔횡파 임계 붕괴) 은 장부에 올라가지 않았다. 관측창 문제가 드러나는 7체에서는 아직 연결되지 않았다.

판정: 대수 관계 252 줄의 PASS 는 유효하나, ⑤ 단계와 관측 단계는 원칙 ② 를 적용하지 않은 계산이다. "6단계 통과" 표현은 이 범위 한정을 붙여 읽는다. 보정은 S120 인수인계 §2.0.

보정 근거 (기존 문서, MAPSI 지시로 확인): v3.4 §16 §4-U (C = GAP = 관측 최소 비용), 원칙 X, §93 (관측 = 상전이), S117 확장번역 v4 §0·§0.1 (C = n·GAP 는 tip 에서만 결정, 1 = h·ν_p + W 지불, 넘친 몫 방출, 잔류 이월, 정수 사이클 33). 아키텍트가 이 문서들을 S119 설계에 대조하지 않은 것이 원인.
