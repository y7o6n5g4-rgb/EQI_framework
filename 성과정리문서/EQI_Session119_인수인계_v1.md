공리 문장 (MAPSI S118): 길이-시간 관측창 상전이의 비평형 정보역학적 기울기 GAP 는 코펜하겐 해석을 하위 클래스로 포섭한다. 1 = 거시 로컬 정규화 (보른 규칙), 1 + n·GAP = 미시 글로벌 재정규화, n 은 복소수 가능.

**§118 이중 공리 정합 (S118, R, 400자리 차 0 확인 / B21 후보)**: 사이클 축에서 x = Z(n), y = p0(n) = 1/Z(n) 로 두면 공리 1 xy = 1 은 모든 n 에서 성립 (볼츠만 BZ-2). 공리 2 x − y = 1 은 Z = 1 + 1/Z, 곧 **n = μ/GAP (Z = φ, §108 ≈ 96/5 점)** 한 곳에서만 성립 → 두 공리가 동시에 성립하는 자리 = 볼츠만 BZ-6 점. 보조: x + y = √5 → GAP = ln 25/100 = 4·ln(x + y)/100 (ln 부분이 두 공리의 합 √5, 1/100 의 근거는 기존 문서 따름).

**S118 작업과의 차이 (재점검 대상)**: S118 의 볼츠만 (v2.3)·란다우어 (v2.4) 는 ②④⑤ 를 거치지 않고 ③ → ⑥ 로 바로 갔음. S119 에서 이 파이프라인으로 다시 통과시켜 기존 결과 (BZ·LD 묶음) 와 대조. 기존 코드·로그는 보존.
**적용 대상 (MAPSI S118 확정)**: 종국적으로 **모든 법칙** 이 파동함수 대입 방향. GAP 공리가 코펜하겐 해석을 하위 클래스로 포섭하므로 결정론적 법칙도 예외 아님.
