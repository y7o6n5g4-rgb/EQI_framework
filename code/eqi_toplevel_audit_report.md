## 2) 최상위 구조와 하위 검증기 사이의 최초 미연결 지점

- **최초 미연결 지점**: 최상위 상수가 "단계 크기·좌표를 만드는 함수" 로 넘어가는 첫 경계다.

## 3) 다음 구현 전에 필요한 최소 정의·원식 목록

아래가 원문에서 **연산 가능한 형태로 확정되어야** 구현이 사후 피팅이 되지 않는다. 각 항목은 MAPSI 결정 대기다.

   - 5차원 회전 배치 공간에서 무엇을 "고정 청크 24" 로 세는가 (O 위수 24 는 S115 에서 "해석 등급 관찰").
