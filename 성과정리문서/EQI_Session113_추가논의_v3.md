### 자기참조 조건 (§6b-Ω)

모든 자기참조 사이클은:

```
x = 1 + 1/x  →  x − x⁻¹ = 1
→ x² − x − 1 = 0
→ x = φ  (유일 양수해)
```

**핵심:** 자기참조 사이클 존재 ⟺ φ 고정점 존재.

### EQI 연역 — 정리(EQI-루퍼트)

**명제:** 볼록다면체 P가 루퍼트 성질을 가진다
⟺ P의 대칭 구조가 φ 고정점을 허용한다.

**증명 개요:**
- (⇒) 루퍼트 통과 = 자기참조 사이클 = φ 존재
- (⇐) φ 존재 → x=1+1/x 사이클 구성 → 통과 경로 존재

**EQI 결론:**
"모든 볼록다면체는 루퍼트 성질을 가진다" = 거짓.
반례가 **필연적으로 존재** (φ 비허용 대칭 다면체).
