## §2. §52 등록 — Murray law 3/8

### §52-A — 3/8 = c지수 × 클라이버 지수  [TZ, 대수필연]

```
3/8 = (1/2) × (3/4)
오차% = 0.0%  ★ TZ(대수필연)

다중 표현 ALL TZ:
  클라이버지수 / 2   = (3/4)/2 = 3/8
  3/(2d), d=4       = 3/8
  (d-1)/(2d), d=4  = 3/8
  1/8 = c지수³      = (1/2)³  [Murray지수3 → 1/8]
```

### §52-B — WBE 스케일링 사슬  [TZ]

```
BMR      ∝ M^(3/4)  [클라이버, §44 TZ]
혈관반경 ∝ M^(3/8)  [Murray law]
3/8 = (3/4) × (1/2) = 클라이버 × c지수

→ 혈관 반경 스케일링 = BMR 스케일링 × 광속 지수
→ φ 순수 지수로 닫히지 않음 [φ^(-2)=0.382, 오차 1.86%]
→ 오직 c지수 × 클라이버 지수의 곱으로만 닫힘
```

### §52-C — §44 지수 사슬 연결  [TZ]

```
수명(1/4) + c지수(1/2) = 클라이버(3/4)  [TZ]
Murray(3/8) - 수명(1/4) = c지수³(1/8)
d=4 언어: 클라이버=(d-1)/d, 3/8=(d-1)/(2d)
```
