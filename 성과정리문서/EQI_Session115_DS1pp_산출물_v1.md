## 검증 대상 공식

```
D'' = (mu + sigma**2 - (13/6)*GD**2)*B - 9*B**2*GD**3
```

## 산출물 ① 재현 가능한 완성 코드

**파일**: `code/s115_ds1pp_formal.py`  
**실행**: `python3 code/s115_ds1pp_formal.py`

```python
from mpmath import mp, mpf, sqrt, log, fabs, nstr, power as mpow
mp.dps = 400

PHI    = (sqrt(mpf(5)) + 1) / 2
GAP    = log(mpf(25)) / 100
GD     = log(mpf(5))  / 100          # GAP_D2
LN_C   = log(PHI) / 2

B      = LN_C**2 * GD               # (B) 계단
A      = B**2                        # (A) 제곱 = LN_C⁴·GD²
mu     = 1 / PHI
sigma2 = mpf(1) / 4
Lambda = mpow(PHI, mpf(-2))

EQI4   = 1 + GAP
R      = EQI4 * mpow(PHI, mpf(9)/2)

D_p    = (mu + sigma2 - mpf(13)/6 * GD**2) * B    # DS-1'
corr   = 9 * B**2 * GD**3                          # 9·A·GD³
D_pp   = D_p - corr                                # DS-1''
```

### ④-C 미해결 귀속

**U-1. 계수 9 귀속 [미해결]**

```

← 약 0.399% 큼 → 9·B²·GD³은 diff_p보다 약 0.399% 작음

후보 A: 9 = L₂²  (루카스 L₂=3)
  → 수치 일치 (L₂²=9), 대수 기원 미확인

후보 B: 9 = φ⁴+φ²−2  (수치 불일치 확인)
  → φ⁴+φ²−2 = 4φ+1 = 7.472... ≠ 9  (φ⁴=3φ+2, φ²=φ+1 이용)
```

**U-2. DS-1' (13/6)·GD² 계수 귀속 [미해결]**


**U-3. (B)/(A) 교차 구조 의미 [미해결]**
