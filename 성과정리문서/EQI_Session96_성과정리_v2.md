```

  (1+GAP)² + φ⁶ = |1+iφ³|² + 2GAP + GAP²

  ├─ GAP  비용 (1배): (1+GAP)² 전개의 GAP 성분
  │    ① 무리수↔유리수 전이: (1+GAP) 분자의 GAP
  │    ② 팩토리얼(순열↔조합): ①과 수학적 등가 (동일 GAP)
  │
  └─ 2GAP 비용 (2배): (1+GAP)² 전개의 2GAP 항
       ③ 허수↔실수 전이: 복소 분해 +2GAP 항
       ④ 벡터곱↔스칼라곱: ③과 수학적 등가 (i = 90° 회전)

→ ①②가 GAP 한 곳에 대응, ③④가 2GAP 한 곳에 대응
→ 각 쌍이 수학적 등가: 팩토리얼↔수체계, 위상↔벡터

비율: 2GAP/GAP = 2 = 비리얼  TZ(대수필연)

항 귀속:
  |1+iφ³|² = 1+φ⁶  [GAP=0 기저, 복소 노름]
  +2GAP             [③④ 비용]
  +GAP²             [2차 보정]
```
