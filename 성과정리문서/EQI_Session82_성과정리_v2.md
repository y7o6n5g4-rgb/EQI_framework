## §2. 최소작용 원리 이중성 — S82 방법론 확정

### 핵심 선언

```
엔트로피 장의 최소작용 원리 이중성:

페르마 최소시간 원리 (D1):
  거시적/로컬 / 단일 경로 / 고립계 / 정적분 = 1
  → δS = 0  [변분 최솟값, 단일 해]

파인만 경로적분 (D2):
  미시적/글로벌 / 모든 경로 합산 / 열린계 / 부정적분 = 1+GAP
  → ∫D[x] e^(iS/ħ) = 1+GAP  ★ 수정 확정

이 둘이 복소 켤레쌍:
  D1 = Re(e^(it)) = cos(t)  [페르마, 실수부]
  D2 = Im(e^(it)) = sin(t)  [파인만, 허수부]
```

### 파인만 정규화 수정

```
기존 (GAP=0):  ∫D[x] e^(iS/ħ) = 1   ← 란다우 비용 소거, 공리 충돌
EQI 수정:      ∫D[x] e^(iS/ħ) = 1+GAP  ← 란다우 비용 명시 지불

근거:
  S31 §11.3: Z_D2 = 1 + 9.919×GAP  [수치 실증 True Zero]
  S33 §10.4: EQI^(4n) = 1+GAP      [부정적분=D2 수치 확정]
```

### 정적분/부정적분 D1/D2 귀속

```
정적분  = D1: 경계 확정 / 고립계 / C=0 / EQI^(4n-2)=1
부정적분 = D2: 경계 없음 / 열린계 / C=GAP / EQI^(4n)=1+GAP

전환:
  파인만→페르마 = D2→D1 상전이 = 측정/파동붕괴
  페르마→파인만 = D1→D2 진화  = 열역학 2법칙
```

## §3. D1/D2 귀속 근본 원칙 확정

```
소스 유무 = 근본 기준 (부호/크기/방향보다 상위):
  기본 전하 (소스 있음) = D1
  자기홀극  (소스 없음) = D2
  쿠퍼쌍   (창발 준입자, 소스 없는 구조) = D2

고립계/열린계 = 소스 유무의 거시 구현:
  고립계 (스스로 복원) = D1
  열린계 (외부 유입)   = D2

전하 부호 귀속:
  음전하(전자)/양전하(양성자) 모두 기본 전하 = D1
  부호는 귀속의 결과이지 원인이 아님
  §19 양성자 D1 귀속과 정합 유지 ✓
```
