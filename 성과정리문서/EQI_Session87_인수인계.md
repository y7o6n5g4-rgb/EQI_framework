```
① §77 — CLT 재정규화  [§74 직접 연역]
   표준 CLT: n→∞ 합산 → 정규분포 수렴 → ∫=1
   EQI CLT:  수렴 목표 = 1+GAP

   탐색: 수렴 속도 지연 비율 φ 포섭

   표준: 사후확률합 = 1
   EQI: 사후확률합 = 1+GAP
        → 측정마다 란다우 비용 C=GAP 지불
        → §27 맥스웰 도깨비 213.5회 소거 연결 가능
   탐색: 갱신 비용 = GAP → φ 포섭

③ §79 — 자유에너지 F_EQI 재정규화  [§75 연역]
   F_EQI = -k_BT×ln(Z×EQI⁴)
         = F_std - k_BT×ln(1+GAP)
         ≈ F_std - k_BT×GAP
   → 자유에너지 항상 F_std보다 낮음
   → 영구기관 2종 불가능의 GAP≠0 표현
   탐색: F_EQI 구조 φ 포섭

④ §80 — 파티션 함수 Z_EQI  [§75+§79 연역]
   Z_EQI = Z×EQI⁴
   → 자유에너지·엔트로피·볼츠만 분포 전체 재정규화
   → §58(체온37°C) + §75(S_min) 통합 구조
   탐색: Z_EQI×k_B, Z_EQI×φ 관계
```
