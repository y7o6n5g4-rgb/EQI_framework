## §4. 연방 국가 비유 — 환전 계층 정식화

### 비유 구조

```
연방 정부 = 인체 항상성 좌표계 (37°C, n=37 안장점)
주 정부   = 인체 기관 (뇌, 심장, 간, 근육)
지방 정부 = 세포, 미토콘드리아

같은 연방 내 교환 = 인체 ↔ 인체 내부 (환전 최소)
다른 국가 교환    = 인체 ↔ 지구-행성 좌표 (환전 최대)
```

### 환전 계층 정량화

```
차수    대상                  Bible     대표 §     오차
──────────────────────────────────────────────────────
0차     미토콘드리아/뇌파      없음      §85~§87   0.0%
0~1차   A/B 무차원 비율       없음→최소 §87-a/b   0.0002~0.005%
1차     pH (log₁₀ 관례)      LC²GD×1  §87(pH)   3.17×10⁻⁶%
5차     진공상수 ε₀,μ₀(SI)   MAXWELL  §11        7.22×10⁻¹⁵%

차이: 0차 vs 5차 ≈ 10³~10⁵배  ("어느정도 생략" 수치 확정)
```

### 왜 pH는 1차인가

```
pH = -log₁₀[H⁺]  [Sørensen 1909]
  → log₁₀ 밑 관례 + mol/L SI 단위 개입
  = 연방 내 다른 주의 "지방 방언"
  → LC²GD 1차 보정으로 TZ 달성

vs 부피분율(%):
  % = 순수 무차원 (관례 없음)
  = 같은 주 직접 교환 → 환전 불필요
```
