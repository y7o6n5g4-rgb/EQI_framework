## A. 기존 모든-축 인증 재현·감사 (q = q0)

**피복 논증**
- u ∈ S² 의 절댓값 최대 성분 |u_i| = m ≥ 1/√3 을 잡는다. 그러면 u/m 은 면 x_i = sign(u_i) 위에 있고, 나머지 두 성분은 [−1, 1] 에 있다.
- 따라서 6면 × [−1,1]² 의 정규화 상이 S² 전체다.
- 각 면을 닫힌 칸 4×4 (끝점 정확 유리수 ±1, ±1/2, 0) 로 나눈다. 칸은 경계를 공유하므로 누락 경계가 없다. 칸 수는 96이다.

**점검 항목**

| 항목 | 결과 |
|---|---|
| 정규화 분모 ‖v‖ | 한 성분이 정확히 ±1 이라 ‖v‖ ≥ 1. 구간 하한 최소 1.000000 → 0 배제 |
| 칸별 증명서 유효성 | 칸마다 lo(d̂_k·U) 가 최대인 k 를 고른다. U 는 칸의 모든 정규화 점을 포함하므로 그 하한은 칸 전체에서 유효하다 (선택만 float 비교, 판정은 구간 하한) |
| 음의 가중치 | 사용한 쌍대 꼭짓점 3개의 w 구간 하한이 모두 > 0. 나머지 7개 조합은 "det ≠ 0 이고 어떤 w 상한 < 0" 으로 **실현불가 인증** (이전 보고의 "비양수 또는 미확정" 을 분리 확정) |
| 분기 미확정 | d̂·U, b̂ 계산에는 max/abs/조건 분기가 없다. 구조 판정 (엄격 내부, 쌍대 부호) 은 미확정이면 제외 또는 실패로 처리한다. 이번 미확정 0 |
| 재현 | 인증 96칸, 실패 0, a0_cert = 0.094877909200231 (내림 표시, 기존과 일치) |

**δ 도출 분리 (q0)**
- 균일: bmax = √3 (기호 상계, 아래 E 참조. 구간 계산 상한은 1.732050807569) → δ_uni = lo(min(1, a0/√3)) = 0.0547777864169.
- 칸별: 칸마다 iv 나눗셈 하한 lo(min(1, a_칸/b_칸)) 을 구하고 그 최소를 취한다 → δ_cell = 0.0656753763868.
- 기존 보고는 mpf 나눗셈 후 nstr 반올림으로 표시했다. 보증 하한과 대조한 결과, 두 표시값 (0.0547777864169, 0.0656753763868) 모두 보증 하한 이하였다. 정정은 필요 없다.
- 새 스크립트는 처음부터 보증 하한을 저장하고 내림으로 표시한다.

**무작위 점검**: 인증 섹션과 분리된 [비인증] 섹션에서 float LP 로만 수행한다.

## B. 바깥 방향 이웃 (사전 고정 입력)
- R_out(q) = Ry(−q1)Rz(−q2), q0 = (2/5, 9/10).
- Q = [2043/5120, 2053/5120] × [4603/5120, 4613/5120] (= q0 ± 1/1024).
- 반폭 1/1024 은 국소정리 시험의 명시적 입력이다. EQI 격자 생성 법칙으로 등록하지 않는다.
- 사전 고정한 방법 매개:
  - Q 하위상자 수준 L ≤ 3 (균일 2^L × 2^L)
  - 구면 초기 4×4, 최대 깊이 7
- 실제로는 **L = 0 (Q 상자 하나) 에서 바로 인증**되었다. 반폭 조정이나 사후 재시도는 없었다.

## C. 공통 회전 구조
- R_in(q, θ, u) = R_out(q)·exp(θ[u]×) 이다. 바깥·안쪽을 독립 회전 볼로 처리하지 않았다.
- 증명서의 접촉 꼭짓점 v_j 는 변 j 의 양 끝 중 하나다. 따라서 각 q 에서 b_j(q) = ν_j(q)·R_out(q)v_j 가 정확 항등식이다 (n_j ⟂ 투영 변 벡터).
  - θ = 0 의 공통항 h_O − h_I = 0 은 구간으로 빼지 않는다. 기호적으로 사라진다.
- 남는 정확식은 다음과 같다.
  - b_j − ν_j·R_out(q)e^{θ[u]×}v_j = −sinθ·u·(v_j × ν′_j) − (1−cosθ)·[(u·v_j)(u·ν′_j) − v_j·ν′_j]
  - ν′_j = R_out(q)ᵀν_j(q)
- sinθ 계수와 1−cosθ 계수만 q 상자 구간으로 감쌌다.

## D. 이웃 전체의 기하·균형 검증 (Q 상자 하나, 구간)
- **오각형 구조**:
  - 꼭짓점 순서 (2, 3, 1, 0, 7) 와 변 5개가 Q 전체에서 유지된다.
  - 각 변에서 나머지 6 꼭짓점이 엄격 내부다: n_j·(p_k − p_a) 상한 최대 −0.00628034 < 0.
  - 각 변에 대해 다른 모든 점이 엄격히 한쪽에 있으므로, 볼록 껍질이 정확히 이 오각형이다.
  - 접촉 구조 변화 없음. θ = 0 접촉 집합은 변 양 끝이다.
- **정확 균형**: 각 q 에서 법선 n_j(q) 는 정확값이다 (비정규화).

| J | det 구간 (Q 전체) | w 하한 | s′(q) 하한 |
|---|---|---|---|
| (0,1,2) | [11.09642563, 11.38854763] | (0.29907950, 0.16898720, 0.51902471) | 1.90691072 |
| (0,1,3) | [6.10995850, 6.25341550] | (0.02454052, 0.02006278, 0.94523348) | 0.18069656 |
| (0,1,4) | [11.81553421, 12.06694830] | (0.18316066, 0.31427755, 0.48587593) | 1.99146977 |

- 해석:
  - det 이 Q 전체에서 0 을 배제하므로, 모든 q 에서 정확 연립해 w*(q) 가 존재하고 유일하다.
  - 구간 LU 해는 모든 q 의 w*(q) 를 포함하며, 하한이 > 0 이므로 w*(q) > 0 이다.
  - 그러면 w*(q) 가 Σw n(q) = 0 의 정확해다. 구간 잔차가 0 을 포함한다는 사실은 논거로 쓰지 않았다.
- 나머지 7개 조합은 Q 전체에서 실현불가로 인증됐다. 미확정은 0이다. 쌍대 꼭짓점 집합은 q0 와 같다.
- [스크래치 독립 점검] Cramer 공식 (iv.det 비) 으로 구한 w 구간이 LU 구간과 겹치고, 모두 양수였다 (예: J(0,1,3) w₀ ∈ [0.02593, 0.03023] vs LU [0.02454, 0.03161]).

## E. 모든 축과 바깥 방향의 결합 인증
- 증명서 24개의 d̂_k(q) = Σw_j(q)(v_j × ν′_j(q))/s′(q) 를 Q 상자 구간으로 감쌌다. 이것은 모든 q ∈ Q 의 정확값을 포함한다.
- 구면 96칸이 모두 깊이 0 에서 인증됐고, 실패는 0이다. 사용 증명서는 13개다.
- **∀q ∈ Q, ∀‖u‖ = 1: max_k d̂_k(q)·u ≥ a_Q = 0.056880738626266 > 0** (보증 하한).
  - 칸에서 고른 증명서의 하한은 q 상자 × 구면 칸 전체에 대한 구간 하한이다.
  - q0 점의 0.0949 보다 작은 이유는 실제 변화보다 q 구간의 감쌈 손실이 크기 때문으로 보인다. float 점검에서 실제 M/θ 는 ≈ −0.216 이었다.
- **이차항 상계 b_Q**:
  - 기호 상계: |ν′·(u×(u×v))| ≤ ‖ν′‖‖v‖ 이고 ‖ν′_j‖ = |n_j| (각 q 에서 R_out(q) 는 정확 직교) 이다.
  - 따라서 b̂_k ≤ Σw_j|n_j|‖v_j‖ / Σw_j|n_j| ≤ max_j‖v_j‖ = √3 (w_j|n_j| > 0) 이고, 이 값은 q 와 무관하다.
  - 구간 직접 계산 상한은 2.062821941340 이다 (감쌈 과대평가). 기호 √3 을 쓴다.
  - 칸별 b̂ 구간 상한의 최대는 1.800093533030 이다.
- **δ_Q (분리 도출)**:
  - 균일: lo(min(1, a_Q/√3)) = **0.0328401097575**
  - 칸별: min_칸 lo(min(1, a_칸/b_칸)) = **0.0573932756328**
  - 두 값 모두 유효하다. 큰 쪽을 채택한다: **δ_Q = 0.0573932756328** (내림 표시).
  - 근거: θ ∈ (0,1] 에서 sinθ ≥ 5θ/6, 1−cosθ ≤ θ²/2 이므로 θ < (5/3)a/b 이면 B < 0 이다. δ = min(1, a/b) 는 그 안쪽이다.
- **주장**: 이 작은 바깥 방향 이웃 Q (q0 ± 1/1024) 에서, 모든 상대 회전축과 0 < θ ≤ δ_Q 의 엄격 포함이 배제된다.
- **θ = 0**: 동일 투영의 경계 사례다 (B = 0). 별도로 둔다.
- **[비인증] 무작위 점검**: q ∈ Q 2000개 × 무작위 축 × θ ∈ {δ_Q, δ_Q/3, δ_Q/30, 1e−4} 에서 실제 float LP 로 계산했다.
  - max M/θ = −0.215656 < 0 이다. 인증과 모순이 없다. 인증 근거는 아니다.
