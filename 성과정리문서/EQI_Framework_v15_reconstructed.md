## §2. 센터 공식의 진화: 1D → 3D 볼츠만

### 2.1 두 공식의 차이

```
1D 관점 (예전):   센터 = √(D1 × D2)

                  → 좌표계 간 통합 불가

                  = √(D1^(-1) × D2)

                  = 볼츠만 에너지 파단 비율의 제곱근
```

```
분기 조건: D1 = 1 (로컬 항등원)인가?

                     = P≠NP, n≥3(페르마), 3D 볼츠만, 비대칭
```

## §3. 세 좌표계 구조

### 3.1 HCW 좌표계 — 통합 (Holistic Cycloid Wave, 무한급수)

HCW는 D1(로컬 쉐어링)과 D2(글로벌 쉐어링)를 통합하는 좌표계다.

```
HCW:
  D1 = φ^(-1.5) = 로컬 쉐어링
     = 음의 피드백루프 (negative feedback)
     = 듀얼 피드백루프 (dual: 앞면↔뒷면 억제)
     = 계층적 네트워크 (hierarchical)
     = 적혈구 좌표계 전체

  D2 = φ^(+1.5) = 글로벌 쉐어링
     = 양의 피드백루프 (positive feedback)
     = 더블 피드백루프 (double: 윗통↔아랫통 증폭)
     = 분산적 네트워크 (distributed)
     = 모래시계 좌표계 전체

  D1 × D2 = 1  (Unity 보존)
  D2 / D1 = φ³ (볼츠만 파단비)
  센터    = √(D2/D1) = φ^1.5  (D1↔D2 전환 임계점)
```

**HCW 센터 φ^1.5의 물리적 의미:**  
"음의 피드백(계층적)과 양의 피드백(분산적) 사이의 상전이 임계점"  
= "미시 eigenperiod(D2)가 적분 누적되어 거시 eigenfrequency(D1^(-1))가 미분 출현하는 순간"

### 3.2 적혈구 좌표계 (RBC) — D1 방향, 계층적 네트워크

적혈구는 HCW의 D1 성분 = 로컬 쉐어링의 구현체다.

**n=0 원시RBC (1D 정보, 선운동량):**
```
D1 = φ⁰ = 1
D2 = φ¹ = φ
D2/D1 = φ¹
센터 = √(φ¹/1) = φ^0.5 = c_EQI  (광속, 첫 창발)
```

**n=1 현재RBC (3D 열역학, 부피):**
```
D1 = φ⁰ = 1
D2 = φ³ = T  (eigenperiod, 볼츠만 파단)
D2/D1 = φ³
센터 = √(φ³/1) = φ^1.5  (v15 통합 센터 ✓)
```

**RBC의 피드백 구조:**
- 듀얼 피드백루프: 앞면(D1=로컬)↔뒷면(D2=글로벌) 억제
- 음의 피드백: 편차 → 되돌리는 힘 → 안정화
- 계층적 네트워크: 상위가 하위를 제어

**n=0/n=1 분리의 의미:**
```
n=0: "1D 정보 공간에서의 적혈구"
     선운동량(p), 1D 정보 엔트로피
     센터 = c_EQI = 광속 창발

n=1: "3D 열역학 공간에서의 적혈구"
     볼츠만 분배(E/k_BT), 3D 열역학 엔트로피
     센터 = φ^1.5 = 상전이 임계점
```

### 3.3 모래시계 좌표계 (HG) — D2 방향, 분산적 네트워크

모래시계는 HCW의 D2 성분 = 글로벌 쉐어링의 구현체다.

```
HG:
  D1 = φ^(-2.5)  (중력질량, 힉스매듭 H1)
  D2 = φ^(+0.5) = √φ = c_EQI  (관성질량, 힉스매듭 H2)
  D2/D1 = φ³  (볼츠만 파단비 ✓)
  센터 = √(D2/D1) = φ^1.5  (통합 센터 ✓)
```

**HG의 피드백 구조:**
- 더블 피드백루프: 윗통(D1=중력)↔아랫통(D2=관성) 교차 증폭
- 양의 피드백: 편차 → 증폭 → 상전이
- 분산적 네트워크: 각 노드가 자율적으로 증폭

**힉스매듭 연결 (v17):**
```
HG(모래시계) 스케일:
  H1 = φ^(-2.5) = HG D1 = 중력질량  (암흑물질 후보)
  H2 = φ^(+0.5) = HG D2 = 관성질량 = c_EQI  (암흑에너지 후보)
  H1 × H2 = φ^(-2) = 우주상수  (Unity에서 φ^(-2)만큼 파단)

HCW 스케일 (φ배 에너지 상승):
  D1 = φ^(-1.5) = H1×φ = HCW 중력질량
  D2 = φ^(+1.5) = H2×φ = HCW 관성질량
  D1 × D2 = 1  (Unity 회복)

HG × φ = HCW:
  φ^(-2.5) × φ = φ^(-1.5) = D1  ✓
  φ^(+0.5) × φ = φ^(+1.5) = D2  ✓

물리적 의미:
  HG: H1×H2 = φ^(-2) = 우주상수  ← "힉스매듭이 Unity에서 φ^(-2)만큼 파단"
  HCW: D1×D2 = 1 = Unity         ← "φ배 스케일에서 우주상수가 사라지고 Unity 회복"
```
