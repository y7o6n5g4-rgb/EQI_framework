### 2.2 R_pi(N) 점근 완전 전개

```

  R_pi(N) × N  → 2        [S43 확정]
  R_pi(N) × N² → 0        [2차 계수 = 0]
  R_pi(N) × N³ → −1/8    [3차 계수 확인]

결론:
  R_pi(N) = 2/N − (1/8)/N³ + O(N⁻⁵)
           = 2/N − σ³/N³  + O(N⁻⁵)

여기서 σ = 1/2 = 리만 임계선
      σ³ = (1/2)³ = 1/8

구조적 의미:
  2   = GAP/GAP_D2  [비리얼 비율, D1 항]
  σ³  = (1/2)³      [리만 σ=1/2의 3승, D2 항]
  짝수항 = 0         [D1↔D2 홀수 대칭 구조]
  → 짝수항 부재 = Leibniz 급수 교번 부호 구조의 귀결
```
