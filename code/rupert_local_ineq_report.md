## A. 대칭군
- 48 부호치환 중 P_{11/20} 꼭짓점 집합을 정확히 보존하는 것은 **24개 (T_d: det +1 12개, det −1 12개)** 다. 중앙반전은 비보존이다.
- 투영 부호 (d ↔ −d) 는 그림자를 반사 합동으로 만든다. 이것은 물체 대칭과 별개의 논증이다.
  - 그래서 그림자 합동 기준 방향 동일시는 {±g : g ∈ T_d} (방향 작용 48개) 다.
  - float 확인: 무작위 20 방향에서 ±g·d 그림자 쌍거리 차 ≤ 8.9e−16.
- 이전 후보 필터에 미친 영향: 없음. abs(·) 로 이미 ±d 를 동일시했으므로 실제 동일시 집합이 올바른 집합과 같다. 후보 0개 결과와 기하 인증은 그대로다.

## C. 동일 방향에서의 한쪽 방향미분 (기존 세 축 × ±, 바깥 고정)

**설정**
- R_out = Ry(−2/5)Rz(−9/10) (정확 유리수 각), R_in(θ) = R_out·exp(θ[a]×).
- 바깥 그림자는 오각형으로, 꼭짓점 반시계 순서 (2, 3, 1, 0, 7), 변 5개다.
- 모든 변에서 다른 꼭짓점이 엄격 내부임을 구간으로 인증했다. 따라서 θ = 0 의 접촉 집합 S_j 는 정확히 변의 양 끝 두 꼭짓점이다.
- 변 법선 n_j 는 변 벡터를 90° 돌린 비정규화 정확값이다.

**기호 정리**
- ν_j = (n_j, 0) 일 때 h_I(n_j, θ) = max_v ν_j·R_out e^{θA} v 이고, θ = 0 에서 h_I = h_O(n_j) = b_j 다.
- Rodrigues 정확식: ν_j·R_out e^{θA} v = ν_j·R_out v + sinθ·α_j(v) + (1−cosθ)·β_j(v).
  - α_j(v) = ν_j·R_out(a×v), β_j(v) = ν_j·R_out(a×(a×v)).
- Danskin 정리로 한쪽 방향미분은 D⁺_j = max_{v∈S_j} α_j(v), D⁻_j = max_{v∈S_j} (−α_j(v)) 다. 최댓값을 내는 꼭짓점이 θ 부호별 접촉이다.
- 평행이동 LP: 바깥이 고정이므로 쌍대 실현가능 영역도 고정이다. θ = 0 에서는 모든 g_j = 0 이라 모든 쌍대 꼭짓점이 최적이다. 따라서 M(θ) ≈ −θ·max_{쌍대 꼭짓점} Σw_j D⁺_j 다 (단위 법선 기준).

**부호별 접촉 (꼭짓점 전환; 구간으로 우열 확정, 동률 없음)**

| 축 | 변 0 (2,3) | 변 1 (3,1) | 변 2 (1,0) | 변 3 (0,7) | 변 4 (7,2) |
|---|---|---|---|---|---|
| (1,0,0) +/− | v2 / v3 | v3 / v1 | v1 / v0 | v7 / v0 | v2 / v7 |
| (0,1,0) +/− | v2 / v3 | v3 / v1 | v0 / v1 | v0 / v7 | v7 / v2 |
| (1,2,3)/√14 +/− | v2 / v3 | v3 / v1 | v1 / v0 | v0 / v7 | v7 / v2 |

- α 값 표는 출력 파일에 있다. 예: 축 (1,0,0) 변 1 은 α(v3) = 1.716170902, α(v1) = −2.936338368.
- 모든 접촉에서 두 꼭짓점의 α 가 구간으로 분리된다. 따라서 θ → 0⁺/0⁻ 에서 접촉이 바로 갈라진다 (1차에서 결정, 2차 비교 불필요).

**계수 도출 (피팅 아님)**
- 정확 균형 쌍대 꼭짓점 (변 3개, 가중치 구간 하한 > 0) 은 3개다: (0,1,2), (0,1,3), (0,1,4).
- 각 쌍대 꼭짓점에서 단위 법선으로 정규화한 기울기 a/s′ 를 구하고 (s′ = Σw_j|n_j|), 그 최댓값을 이전 관측과 대조했다.

## D. 국소 부등식
- 정확 균형 증명서:
  - 가중치 w 는 Σw n_j = 0, Σw = 1 의 정확해를 감싼 구간이다 (정확 법선의 구간 연립해). 따라서 잔류 균형 r = 0 이 정확히 성립하고, T_max‖r‖ 항이 없다.
  - 고정 꼭짓점 v_j* (부호별 접촉) 의 내적은 h_I 의 하계다. 따라서
    B(θ) ≤ Σw_j [b_j − ν_j·R_out e^{θA} v_j*] = −sinθ·a + (1−cosθ)·b′,  a = Σw α_j(v_j*), b′ = −Σw β_j(v_j*).
  - 이 식은 Taylor 근사가 아니라 정확 항등식이다. 경로 위에서 실제 최대 꼭짓점이 바뀌어도 하계는 유효하다 (전환은 h_I 를 키워 B 를 낮출 뿐).
- sinθ ≥ θ − θ³/6, 1−cosθ ≤ θ²/2 (θ ≥ 0) 를 쓰면 θ ∈ (0, 1] 에서 B(θ) ≤ −a_lo·θ + C·θ², C = a_lo/6 + max(b′_hi, 0)/2.

| 경로 | a (비정규화, 구간) | b′ | C | δ = min(1, a/C) | 결론 |
|---|---|---|---|---|---|
| (1,0,0) + | 1.097103594275 | 0.505829668164 | 0.4358 | 1 | 0 < θ ≤ 1 에서 B < 0 |
| (1,0,0) − | 0.155631403269 (쌍대 꼭짓점 (0,1,3)) | 0.047934372590 | 0.0499 | 1 | 0 < −θ ≤ 1 에서 B < 0 |
| (0,1,0) + | 2.003275992011 | 0.991616655684 | 0.8297 | 1 | 증명 |
| (0,1,0) − | 1.319531660523 | 0.572233419915 | 0.5060 | 1 | 증명 |
| (1,2,3)/√14 + | 2.282137415103 | 1.903339457802 | 1.3320 | 1 | 증명 |
| (1,2,3)/√14 − | 2.529963549367 | 1.769646207583 | 1.3065 | 1 | 증명 |

(구간 폭 ~1e−40. a 는 비정규화 법선 기준이라 쌍대 꼭짓점마다 크기가 다르다. 부호와 δ 만 의미가 있다.)

- **증명된 범위**: 각 경로 (기존 세 축 × ±, 바깥 고정, 1차원) 위의 점 배치 0 < |θ| ≤ 1 에서 B(θ) < 0. 즉 엄격 포함이 배제된다.
  - δ = 1 은 sin/cos 다항 경계를 θ ≤ 1 로 제한했기 때문에 생긴 절단이다. 더 넓은 범위는 주장하지 않는다.
- **θ = 0**: 별도 경계 상태로 둔다. 정확 균형 증명서로는 B(0) = 0 (모든 g_j = 0) 이다. 국소 정리 범위 (0 < |θ|) 에 넣지 않는다.
- **근사 균형의 한계**: float 가중치를 쓰면 B(θ) ≤ −aθ + Cθ² + T_max‖r‖ (‖r‖ ~ 1e−16) 가 된다. θ ≲ T_max‖r‖/a ~ 1e−16 에서는 상수 항이 일차 음수항을 가려 0 근방 인증이 불가능하다.
  - 이번에는 정확해를 감싼 구간 가중치로 r = 0 을 정확히 확보했으므로 이 문제가 없다.
- **범위 밖**:
  - 5차원 이웃 (바깥 회전 변화 포함)
  - 다른 회전축·전체 방향
  - 동일 방향 이외의 대칭 연결 배치 (g ∈ T_d)
  - 전역 비루퍼트 판정
