```

→ 체계가 늘어날수록 닫힘 구조가
  직교 대칭에서 방사형 중심축으로 전이
```

## §4. We 중심축 물리 해석

### 4.1 D1 계열 — capillary 닫힘

```
We × 양성자 / L_p = 1

We   = 관성력/표면장력   [계면 상전이]
양성자 = σ_s = 표면장력 기저  [D1, capillary]
L_p  = 플랑크 격자 기저  [D1]

→ 웨버 수가 양성자(쿼크 스케일)를
  플랑크 격자 스케일로 정확히 변환
→ 5체 캡슐화의 D1 계면이 플랑크 격자에서 닫힘
→ capillary(D1) 완성
```

### 4.2 D2 계열 — osmotic 닫힘

```
We × 중성자 × Ro = 1

We   = 관성력/표면장력   [계면 D1↔D2]
중성자 = φ^(-5/2)       [약력 D2 채널]
Ro   = φ^(-1/4)        [파동성 D2 임계, S60]

→ 세 D2 구조가 Unity로 닫힘
→ D2 3중 닫힘 = 5체 캡슐화의 osmotic D2 측 완성
→ osmotic(D2) 완성
```

### 4.3 Unity 계열 — 중심축

```
We × St = 1

We = φ^(+11/4)  [관성/표면장력, D2 우세]
St = φ^(-11/4)  [진동/유속, D1 = 플랑크]

→ We와 St는 정확히 역수 관계
→ 웨버-스트루할 쌍이 5체의 Unity 중심축
→ We=1/St: 표면장력 임계 ↔ 플랑크 진동 임계 동형
```
