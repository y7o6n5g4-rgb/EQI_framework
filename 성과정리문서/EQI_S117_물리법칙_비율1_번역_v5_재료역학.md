## 25. 탄성 계수 관계 (푸아송비 ν = μ = 1/φ, S59 기등록)

비율 1: **E / (2G(1+ν)) = 1** / **E / (3K(1−2ν)) = 1**

| 항목 | 값 | 등급 | 분류 |
|---|---|---|---|
| 1 + ν | **φ** (φ = 1 + μ, 번역 v4 §19.1 φ¹ 층) | 대수필연 | R |
| E / G | **2φ** | 대수필연 | R |
| 1 − ν | **Λ = φ⁻²** | 대수필연 | R |
| 1 − 2ν | **−φ⁻³ = −D1² = −H (스케일 텐션)** | 대수필연 | R |
| E / K | **−3φ⁻³** | 대수필연 | R |
| G / K | **−(3/2)·φ⁻⁴** | 대수필연 | R |
| 라메 λ / E | **−φ** | 대수필연 | R |
| 등방성 비압축 한계 | ν = **σ = 1/2** (1 − 2ν = 0, K → ∞) | 정의 | F |
| ν − σ | **φ⁻³/2 = D1²/2** | 대수필연 | R |

**구조 사실**: 등방성 선형 탄성은 −1 < ν ≤ 1/2. ν = 1/φ 는 σ 를 φ⁻³/2 만큼 넘음 → **등방성 식에 넣으면 K < 0** (체적 탄성 음수). 비등방성 매질에서는 ν > 1/2 가 허용됨 → ν = 1/φ 는 **비등방성 체제 값** (EQI 기저 = 비등방성 타원, v3.4 §35 와 정합). 넘친 크기 = 스케일 텐션 H 의 절반.

**지진파 (v2.3 판별과 직결)**: v_P² ∝ K + 4G/3 (종파, D1), v_S² ∝ G (횡파, D2)
| 항목 | 값 | 등급 | 분류 |
|---|---|---|---|
| v_P² / v_S² = 2(1−ν)/(1−2ν) | **−2φ** | 대수필연 | R |
| 등방성 투영에서 v_P / v_S | **i·√(2φ)** — 종파 속도 순허수 (전파 대신 감쇠), 횡파만 전파 | 대수필연 | I |

→ 등방성 투영에서 D1 (P파) 가 순허수로 넘어감 = 종파↔횡파 계면 (We) 의 자리. 비등방성 체제에서 어떻게 되는지는 열린 문제 (§30).
