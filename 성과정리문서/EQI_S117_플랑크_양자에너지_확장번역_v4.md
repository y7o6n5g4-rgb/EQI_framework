## 0. 통일 (MAPSI S117) — 상전이 = 파동붕괴 = 정보역학적 광전효과 = 맥스웰 도깨비

### 0.1 n·GAP = 부정적분 상수 C (MAPSI S117)

| 틀 | 식 | 상태 |
|---|---|---|
| 확률론 (D2, 파인만) | ∫ f = F + **C**, C = n·GAP (사이클마다 +GAP 이월, 공통 모듈 [K] TRANSFER = GAP = "뉴턴 +C") | C 미결정 = 가능한 원시함수 전체의 앙상블 = 중첩 |

| 결정론 (D1, 페르마) | 정적분 F(b) − F(a): C 약분 → 값 하나 = **1** | 결정 |

- 미적분에서 적분상수는 경계조건으로만 정해짐 → **임계치 TIP = 경계조건**, 경계조건 부여 = 측정 = 파동붕괴

## 6. 자진스키 — 사가와-우에다 연결 (번역 v4 §16 위에)

### 6.1 비율 1 두 개 → 확장
| 등식 | 번역 v4 (비율 1) | 확장 번역 | 틀 |
|---|---|---|---|
| 자진스키 + 되먹임 (효능형) | ⟨e^(−β·W_diss)⟩ = γ | **γ = Z(n) = 1 + n·GAP = 1 + C** | 부정적분 (확률론, D2 쪽 앙상블) |
| 사가와-우에다 | ⟨e^(−β·W_diss − I)⟩ = 1 | **I = ln Z = ln(1 + n·GAP)** 이면 Z·e^(−I) = **1** | 정적분 (결정론, D1) |

- **정보 항 I 가 적분상수 C 를 약분하는 장치** — e^(−I) = 1/(1 + n·GAP) (MAPSI §0.1 의 "부정적분 → 정적분" 이 사가와-우에다 등식 그 자체) — I
- 공통 모듈 우로보로스 **T_n = φ⁻³/(1 + n·GAP) = φ⁻³·e^(−I)** (차 0) — 원칙Y 의 T_n 은 사가와-우에다 정보 인자에 HCW D1 (φ⁻³) 을 곱한 것 — I
- (분석 메모) 실수 n = 라플라스형 (⟨e^(−βW)⟩), 허수 n = 일 분포 특성함수형 (⟨e^(iuW)⟩), 복소 n = 생성함수 — 극형 위상 n_im·IG 의 자리 — I
