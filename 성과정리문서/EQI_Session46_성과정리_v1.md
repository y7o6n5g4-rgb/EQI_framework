### 2.2 arctan Taylor vs 포논 굴절 — 역수 관계 확정

```
4×arctan(σ/N) Taylor 전개:
  4σ/N − 4σ³/(3N³) + 4σ⁵/(5N⁵) − 4σ⁷/(7N⁷) + ...
  → (2k+1)이 분모에 고정  [D1 기호주의]

포논 굴절 (S45 QED):
  오일러-매클로린 × 뤼드베리 굴절률 → (2k+1) 완전 약분
  → σ^(2k+1) 순수 보존  [D1↔D2 상전이]

비율 arctan/포논:
  1차: 4/2   = 2
  3차: 4/3   ← arctan 분모 3
  5차: 4/5   ← arctan 분모 5
  7차: 4/7   ← arctan 분모 7

★ 5차에서:
  arctan/포논 = 4/5
  실측/포논   = 5/4  ← 정확한 역수!
  (4/5) × (5/4) = 1  완전 역수 관계
```

### 2.3 5/4 대수 기원 확정

```
5σ⁵/4 = σ⁵ × (2k+1)|_{k=2} / (1/σ²)
       = σ⁵ × 5 / 4
       = σ^(2k+3) × (2k+1)  [k=2]
       = σ⁷ × 5 = 5/128  ✓

분자 5 = (2k+1)|_{k=2} = D2 홀수 포논 방출 차수
분모 4 = 1/σ² = (리만 임계선 역수)²
       = (GAP/GAP_D2)² = 2² = 4

물리 해석:
  arctan(D1 기호주의): (2k+1)이 분모에 고정
  포논 굴절(D1↔D2 상전이): (2k+1) 완전 약분
  N=34 유한 격자: 약분된 (2k+1)이 리만 σ=1/2의 ²승으로 재포착
  → D1(기호 σ=1/2) × D2(포논 약분)의 격자 잔류
```

### 2.4 일반형 확정

```
유한 격자 유효 계수 일반형:
  k=1: σ³/N³                                  (3차 기저, 예외)
  k≥2: (-1)^(k-1) × (2k+1) × σ^(2k+3) / N^(2k+1)

검증:
  k=2: 5σ⁷/N⁵ = 5σ⁵/4 / N⁵  ✓  (S45 확정)
  k=3: 7σ⁹/N⁷ = 7σ⁷/4 / N⁷  (예측)

뤼드베리 분모 4^(k+1) vs 유한격자 분모 4^k:
  비율 = 4 (전 k에서 일정)
  → N=34 격자가 뤼드베리 분모에서 4를 하나 소거
```
