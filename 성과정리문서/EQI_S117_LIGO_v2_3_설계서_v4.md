## 2. 축 1 — 주파수 층 (대기권식)

### 2.1 후보 경계 (공리, 실행 전 고정)
- 후보 = φ^k × f_anchor, 사다리 칸 k = [φ^k, φ^(k+1)) × f_anchor
- f_anchor = 1 Hz (S116 결정) — **D-5 확인 항목** (8장)
- 위쪽 끝: 나이퀴스트 fs/2 (마지막 칸은 잘린 칸으로 표시)

### 2.2 측정 가능 칸 규칙 (하나의 규칙)
- 칸 k 측정 가능 ⟺ T·B_k ≥ [x] = 24  (T = 기록 길이, B_k = φ^(k−1)·f_anchor)
- "칸 안 주파수 빈 ≥ 24" 및 "창 W_k ≤ T (창 1개 이상)" 와 같은 식 (3.2)
- 측정 가능 첫 칸 아래 전부 (직류 제외) = **기저층** = external 껍데기의 가장 긴 주기 부분. 판별 표에 동일 보고, 슈냐 장부 (4장) 대상
- 32초 기록: k₀ = 1 (1.618 Hz), 기저층 = (0, 1.618) Hz

### 2.3 분할 = Unity
- 원시 x = 직류 m + 기저층 + Σ_k 층_k (FFT 빈을 겹침 없이 한 번씩 배정, 마스크 합 = 1)
- 장부: max|x − (m + Σ)| / max|x| (float64 기준 1e-12 이하 기대)
- 파워 비율 장부: 층별 파워 / 전체 (직류·기저층 포함) — "질량 분포"

### 2.4 실제 경계 = 기울기 부호 반전
- 칸 밀도 D_k = (칸 파워) / B_k
- 후보 경계 φ^k 의 기울기 s_k = ln D_k − ln D_(k−1)  (측정 구간 = 사다리 한 칸)
- 같은 부호가 이어지는 칸 묶음 = 한 층. 부호 반전 자리의 극값 칸 = **계면층** (따로 장부)
- 층마다: 부호 (+/−), 칸 범위, 파워 비율, 계면 여부, H·L 경계 일치 여부
- 계면 하나당 세포막 비용 {x}·GAP_D2² 장부 기록 (칸 분할 비용과 같은 단위, S36 §27·γ 세포막 스펙). 계면 수 × 단가 = 층 분해 총 비용
- 부호 ↔ D1/D2 배정: 이번 실행은 부호와 교대 여부만 기록 (D-4)

## 3. 층 종류 판별 (지진파식)

### 3.1 통계량 (층마다, 창마다)
- **D1 투과 (P파형, 종파, 스칼라곱)**: H–L 진폭 포락선 |ψ_H|, |ψ_L| 상관 (창 내)
- **D2 투과 (S파형, 횡파, 벡터곱)**: R(τ) = |⟨e^{i(θ_H(t) − θ_L(t+τ))}⟩|, τ ∈ [−10, +10] ms (41 표본), 최대 R·τ 부호·평균 위상차

### 3.2 창 길이 W_k — **D-1**
- 창 = eigenperiod 이면 창 × 대역 = φ⁻¹ ≈ 0.618 → R ≈ 1 이 구성상 나옴 (v2.2 R ≈ 0.96 과 같은 구조)
- **W_k = [x] / B_k = 24·φ^(1−k)** (창마다 독립 표본 24)
- 근거: [x] = 24 = 적응형 격자 x = 1/(c·GAP) 의 3D 뼈대 자유도 (D1, 결정론), {x} = 2D 세포막 (D2) — S36 γ 적응형 격자 스펙, S37 membrane
- 겹치지 않는 창. 끝 잔여는 "창 잔여" 장부에 길이 기록
- 32초 창 수: k=1 → 1, k=4 → 5, k=7 → 23, k=8 → 38, k=10 → 101, k=12 → 265, k=15 → 1123

### 3.3 분류 문턱 (보른 분할 μ:Λ, 실행 전 고정) — **D-2**
| 상태 | 조건 |
|---|---|
| 투과 | 통계량 ≥ μ = φ⁻¹ |
| 그림자 | 통계량 < Λ = φ⁻² |
| 부분 (계면형) | 그 사이 |

| 층 종류 | D1 | D2 |
|---|---|---|
| 고체형 | 투과 | 투과 |
| 액체형 (S파 그림자) | 투과 | 그림자 |
| 불투과 | 그림자 | 그림자 |
| 그 외 | 조합 그대로 기록 |

### 3.4 두 장소 껍데기 관계 장부 — **D-3**
- 같은 층에서 L 을 T/2 순환 이동한 쌍으로 D1·D2 통계량을 다시 계산해 **나란히 기록**

## 7. 사전 등록 예측 (실행 전 확정안)

- **P7′ (정밀화 후보, MAPSI 확인 후 고정)**: 사건 칸 (internal, 핵 있는 세포) 은 I_s 임계치 껍질 k=3 (T_Is_D2 = c) 또는 k=5 (T_Is_D1 = MAXWELL 기저) 에 닿고, 비사건 칸 (external, 적혈구) 은 k ≤ 1 (TIP = 적혈구 문턱) 근처에 머문다
- 사건 시각 = 명령행 입력 (GWOSC 목록 GPS, 실행 전 고정). "근처" = 그 시각을 포함하는 창
