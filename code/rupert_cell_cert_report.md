## 1. 기존 보고서 (`rupert_cert_verify_report.md`, 커밋 `ba81fda`) 의 수학적 범위 정밀화

기존 보고서 파일은 수정하지 않았다. 아래 내용은 그 보고서 2.1절 수정식의 정밀한 범위다.

1. **T_max 보정식의 범위**
   - (Σwg + T_max‖r‖)/Σw 는 ‖τ‖ ≤ T_max 로 제한한 문제의 상계다.
   - 제한 없는 문제의 M 상계가 아니다. r ≠ 0 이면 r·τ 가 τ 에 따라 무한히 커질 수 있기 때문이다.
2. **제한이 포함 가능한 모든 평행이동을 담는다는 논증**
   - 회전 중심을 원점 (꼭짓점 좌표 기준) 으로 둔다. 투영은 회전 후 (x, y) 를 취하는 직교 투영이다.
   - R_O = max_v ‖v‖ (바깥 물체, 투영 전 3D), R_I = λ·max_v ‖v‖ (안쪽) 로 정의한다. 둘 다 회전 불변이다.
   - 직교 투영은 거리를 늘리지 않으므로, 모든 회전 배치에서 그림자는 평면 원점 중심 반지름 R_O, R_I 원판 안에 있다.
   - I + τ ⊂ O 이면 I 의 임의 점 y (‖y‖ ≤ R_I) 에 대해 y + τ ∈ O 이다. 따라서 ‖τ‖ ≤ ‖y+τ‖ + ‖y‖ ≤ R_O + R_I = T_max.
   - 따라서 엄격 포함을 실현하는 τ 는 모두 제한 안에 있다. 그러므로 "B ≤ 0 ⇒ 엄격 포함 없음" 은 제한 없는 결론이다.
   - 0 ∈ I 이면 ‖τ‖ ≤ R_O 로 더 좁힐 수 있다. 이번에는 보수적으로 R_O + R_I 를 사용했다.
3. **단위 법선 조건**
   - 증명서 부등식 h_I(n) + n·τ < h_O(n) 는 지지함수의 양의 동차성 때문에 임의의 0 아닌 n 에서 성립한다. 따라서 n 이 단위 벡터이거나 실제 변 법선일 필요는 없다.
   - U/L 식은 단위 n 을 가정한다. 그래서 일반형으로 고쳐 썼다: R → |n|·R, q = n·w0, p = ‖n × w0‖.
   - 방향 성분을 float 이진값 (정확한 유리수) 으로 두고, |n| 은 구간으로 계산했다. 이렇게 하면 단위 법선 오차가 증명 안에서 정확히 처리된다.
4. **p 와 외향 반올림**
   - p = ‖n × w0‖ 로 계산했다. 제곱합은 구간에서도 음수가 되지 않으므로 sqrt 가 안전하다.
   - 모든 양을 mpmath.iv (외향 반올림) 로 계산했다.
   - U 분기 조건 q ≥ |n|R cosρ 와 L 분기 조건 q ≤ −|n|R cosρ 의 부호가 구간으로 확정되지 않으면 자명 경계 U = |n|R, L = −|n|R 를 쓴다. 자명 경계는 항상 유효하다.
   - ρ ≥ π 이면 자명 경계를 쓴다. ḡ_j 상한은 (U 상단점) − (L 하단점) 이다.

## 2. 칸 단위 정리 (바깥 법선 변화 처리)

- 검사 방향 n_j 는 칸 중심 배치에서 고르고, 칸 전체에서 고정한다. 회전 후 다각형의 실제 변 법선이라고 가정하지 않는다.
- 모든 배치 q 에 대해 다음을 U/L 로 보장한다:
  - h_O(q,n_j) ≤ max_v U(n_j, R_out0 v, ρ_out) =: upper_h_O_j
  - h_I(q,n_j) ≥ max_v L(n_j, R_in0 v, ρ_in) =: lower_h_I_j
  - h_I 쪽은 "최댓값 ≥ 각 꼭짓점 하계의 최댓값" 으로 묶는다.
- 엄격 포함이면 모든 j 에 대해 n_j·τ < ḡ_j 이다. 가중합하면 r·τ < Σwḡ 이고, ‖τ‖ ≤ T_max 이므로 Σwḡ + T_max‖r‖ > 0 이 포함의 필요조건이다.
- 따라서 B = [Σwḡ + T_max‖r‖]/Σw ≤ 0 이면 칸 전체에서 엄격 포함이 배제된다. 정확 균형 (r = 0) 이면 T 항이 소거된다.
- B 의 부호를 구간으로 확정하지 못하면 UNKNOWN 이다. 무작위 샘플은 판정에 쓰지 않는다 (sanity 로만 출력).
- **회전 인코딩**: R8 과 동일하다. R_out = Ry(−θ₁)Rz(−φ₁), R_in = Rz(α)Ry(−θ₂)Rz(−φ₂).
- **상대 회전각 상계**: ρ_out = h_θ₁ + h_φ₁, ρ_in = h_α + h_θ₂ + h_φ₂ (반폭 합).
  - 근거: 축 회전 곱에서 회전각 거리는 양측 불변이고 삼각부등식을 만족한다.
  - R v = (R R0ᵀ)(R0 v) 이고 ∠(R R0ᵀ) = d(R0, R) ≤ ρ 이므로, U/L 의 기준점은 w0 = R0 v 다.
- 회전 볼은 Euler 칸의 상을 포함하는 상위집합이다 (같은 집합 아님). 반폭은 단위시험 입력값이며 EQI 격자 세분 법칙으로 등록하지 않는다.

## 4. 해석과 한계

- **인증된 것**: B, P1 칸에서 엄격 포함이 배제된다 (P1 은 λ = 1, P_{11/20} 의 해당 5차원 각도 칸 전체). C 는 해당 1차원 회전 구간 전체에서 배제된다.
  - 모두 구간 산술 (외향 반올림) 결과다. 방향·가중치는 float 이진값을 정확한 입력으로 쓴 것이고, 증명의 정당성은 그 선택과 무관하다.
- **C vs C3D**:
  - C 의 이전 보증은 "평면 그림자의 평면 회전" 에 대한 것이었다.
  - 같은 각도 반폭이라도 3D 물체의 회전 볼 (탈평면 회전 포함) 은 더 큰 집합이라 UNKNOWN 이 나왔다.
  - 3D 칸 인증에는 칸을 더 작게 나누거나 회전 집합을 더 정밀하게 묶어야 한다.
- **보수성 원천**:
  - (i) Euler 칸 → 회전 볼 상위집합
  - (ii) 꼭짓점별 독립 U/L (같은 회전 공유 무시)
  - (iii) T_max = R_O + R_I
  - (iv) 칸 전체에 고정된 방향 n_j
- **인증 아님**: 중심 배치 LP (float), 무작위 sanity 샘플.
- **동일 방향 (대칭 연결) 칸은 이 방법으로 원리적으로 닫히지 않는다.** R8 진단과 일치한다.
