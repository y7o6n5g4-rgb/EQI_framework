## A. 보조정리 문구 정밀화
`rupert_cert_errata.md` 참조. 요지는 다음과 같다.
- 0 ∈ conv{n_j} 는 비음수 균형 가중치가 존재하기 위한 조건이며, 평행이동 LP 의 M 이 유한하기 위한 조건이다. 이것을 유계성과 동일시하지 않는다.
- 비어 있지 않은 full-dimensional H-polytope 가 유계일 조건은 법선의 positive spanning (⇔ 0 ∈ int conv{n_j}) 이다.
- 기존 보고서 (`ba81fda`) 의 "(O 유계 ⇔ 쌍대 실현가능)" 문구가 틀렸다. 원본은 유지하고 정정 메모만 남겼다. 기존 결론은 바뀌지 않는다.

## B. 재현 가능한 증명서 (`rupert_cell_compare_certificates.json`)
P1, P2, C3D 각각에 대해 다음을 저장했다.
- **물체**: P_t 의 p_i, t = "11/20", 정확 꼭짓점 문자열. C3D 는 정육면체와 안쪽 배율 26/25.
- **칸**: 중심·반폭은 float hex (정확 이진값). 구간 [c−h, c+h] 는 iv 외향 반올림이라고 명시했다.
- **회전**: 인수 순서와 Rz/Ry 행렬 정의, 각도 순서 x = (α, φ₂, θ₂, θ₁, φ₁), 투영 convention (회전 후 (x,y), 회전 중심 원점), ρ 상계식.
- **검사 방향·가중치**: 인증기 내부에서 실제 사용한 float 값을 hex (정확) 와 repr 로 저장했다. 화면에 반올림해 표시한 값은 재사용하지 않는다.
- **방법별 값**: Σw 구간, 잔류 균형 r 구간, T_max 정의와 구간, 방향별 outer upper / inner lower, B 구간, 판정, 시간.
  - 모든 구간 끝점은 man × 2^exp2 형태로 정확히 저장했다 (dec 필드는 표시용 30자리).
- **환경**: 정밀도 iv.dps = 40, 패키지 버전, 시드, 선택 규칙.
- 참고: 이번 P1 중심은 float 이진값 0.7 등이다. 이전 실행 (`d3961a3`) 은 십진 문자열 "0.7" 을 썼다. 그래서 칸 중심이 ~1e−17 다르고, B 도 ~1e−16 차이가 난다 (−0.16572197615552012 vs −0.16572197615552003).

## C. 비교 대상 선택 결과
- 조사 조건:
  - P_{11/20}, 시드 20261022, 배치 공간 Λ = [0,2π]²×[0,π]×[0,π/2]² 균등 표본.
  - 상한 2000개 또는 60초.
  - 선택 기준 (사전 고정, 시험용): float LP M_center ∈ [−1e−3, −1e−6] 이고 비대칭각 > 0.05 rad.
  - 비대칭각 = 몸체 투영 방향 d = Rᵀe_z 사이의, 48개 부호치환 (O_h) 중 최소각.
- **조사 2000개 (9.6 s), M 범위 내 0개 → 선택 0개.** 이번 시드와 상한으로는 비교용 경계 근방 칸을 확보하지 못했다.
- 분포 (참고, 선택에 쓰지 않음): M_center 최대 −6.56e−2, 중앙 −0.403, 최소 −0.722. M > −1e−2 인 표본도 0개다.
- 해석: 균등 표본에서 M ≈ 0 근방은 부피가 매우 작다. 동일 방향·대칭 연결 근방이거나, t = 0.55 에서 통과에 가까운 배치 근방이기 때문이다.

  - (b) 조사 상한 확대

- **방향별 비교 (M2 가 M1 보다 나쁜 경우 그대로 기록):**
  - P1: outer upper 는 M2 가 3/3 방향에서 더 타이트, inner lower 는 3/3 방향에서 M1 이 더 타이트. 합산 B 는 M1 이 약간 우세하고, 결합 M3 가 가장 좋다.
  - P2: 각 경계에서 1/3 방향만 M2 가 더 나쁘다. M3 가 두 방법보다 낮은 B 를 주지만 여전히 양수 (UNKNOWN) 다.
  - C3D: M2 (Rz(θ) 인수 구간) 의 inner lower 가 2/2 방향에서 더 나쁘다.
    - 원인은 구간 의존성이다. 같은 θ 의 cos·sin 을 독립 구간으로 다뤄 확장이 생긴다.
    - M1 볼은 C3D 에서 더 큰 집합 (탈평면 포함) 인데도 더 좋은 경계를 줬다.
    - 다만 C3D 의 M1·M2 는 서로 다른 회전 집합 (볼 ⊇ 평면 회전) 이므로 참고 비교다.
- **M2 가 항상 더 타이트하지는 않다.** 방향·꼭짓점에 따라 우열이 바뀌며, 결합 M3 는 정의상 둘 중 나쁘지 않은 쪽을 택한다.
- 인증 개수: 회귀 3칸 중 각 방법 1칸 (P1). 선택 칸 0개.
- 무작위 sanity (비인증): P1 실제 M 최대 −0.1703, P2 실제 M 최대 −1.31e−5. 모두 최선 B 상한 이하로, 정리와 모순이 없다.
- 동일 방향 칸 (P2) 은 별도 국소 논증 없이 닫지 않았다. 양의 B 는 통과 인증이 아니다.

## 한계
- M2 의 구간 의존성: 각도 구간 하나에서 나온 cos/sin 을 독립으로 취급한다. 테일러 모델이나 아핀 산술을 쓰면 개선될 수 있다.
- M1 은 SO(3) 볼 상위집합이고 꼭짓점별 독립 경계다.
- 중심 배치 LP 와 방향·가중치 선택은 float 이다 (정당성과 무관, 인증 입력값은 정확 저장).
- 경계 근방 칸 비교는 표본 0개로 수행하지 못했다. 이번 비교는 회귀 칸 3개에 한정된다.
