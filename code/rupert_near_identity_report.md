## A. 구간 노름 점검

- **문제**: 보존본 `inorm` 은 Σ x*x 를 쓴다. mpmath.iv 에서 x*x 는 독립 곱으로 계산된다.
  - 0 을 포함하는 x = [−1e−3, 2e−3] 이면 x*x = [−2e−6, 4e−6] 처럼 음수 하한이 생긴다.
  - 그러면 `iv.sqrt` 가 `ComplexResult` 예외를 낸다 (거짓 인증이 아니라 예외로 중단).
- **수정 (`rupert_iv_robust.py`)**: Σ x**2 를 쓴다. 결과는 [0, max²] 로 포함 관계를 유지하고 더 좁다. 예외는 잡지 않고 그대로 전파한다.

| 시험 | 보존본 | 견고판 |
|---|---|---|
| 영벡터 | 0 | 0 |
| 성분마다 0 포함 작은 구간 벡터 | **예외 ComplexResult** (Σx*x = [−2.03e−6, 4.09e−6]) | [0, 0.0020224] |
| 정확 평행 n ∥ v (ρ = 0, π/7, π) | U, L 정상 (2/2, 2/1.8019, 2/−2) | 동일 |
| 거의 평행 (1e−20) | 정상 | 동일 |
| 반평행 | 정상 | 동일 |
| 0 포함 구간 v (ρ = 0, π/7, π) | **U, L 모두 예외** | U = [0, 0.0020224], L = [−0.0020224, 0] |

- **회귀**: A, B, C, C3D, P1, P2 의 B 구간 끝점이 보존본과 견고판에서 **완전히 일치**했다.
  - 이 회귀 입력들에는 0 을 가로지르는 구간 성분이 없었다. 따라서 보존본의 기존 결과에는 영향이 없다.
  - 판정은 A UNKNOWN, B 인증, C 인증, C3D UNKNOWN, P1 인증, P2 UNKNOWN 으로 이전과 같다.
- 위험 지점: p = ‖n × w0‖ 에서 n ∥ w0 이면 외적 성분 구간이 0 을 포함할 수 있다. 이 경우 보존본은 예외로 멈췄을 것이다. 거짓 인증 위험은 없었지만, 견고판이 필요하다.

## B. 동일 방향 근방 진단 프로토콜 (사전 고정)

- 물체 P_{11/20} (정확).
- 바깥 회전 R_out = Ry(−0.4)·Rz(−0.9) (기존 P2 중심의 바깥 회전).
- 안쪽 회전 R_in(θ) = R_out·exp(θ[a]×), a ∈ {(1,0,0), (0,1,0), (1,2,3)/√14}.
- θ = ±(1/10)·2^(−k), k = 0..12, 그리고 θ = 0 기준점. 총 81 점 배치 (조사 상한 확대 없음).
- 이것은 '동일 방향 근방 진단' 이라는 별도 시험이다. 기존 '비대칭각 > 0.05' 시험을 대체하거나 성공으로 처리하지 않는다.
- 간격은 진단용이며 EQI 세분 법칙이 아니다.

## D. 작은 이웃 시험

- 사전 순서: 축마다 첫 인증 사례 1개, k 오름차순, + 먼저. 선택 결과 3축 모두 k = 0, θ₀ = +0.1.
- 이웃: 매개 (θ₁, φ₁, θ), 반폭 h = |θ₀|/8 = 0.0125.
  - R_out = Ry(−θ₁)Rz(−φ₁), R_in = R_out·exp(θ[a]×).
  - 볼: ρ_out = 2h, ρ_in = 3h.
  - 인수: v → exp(θ[a]×)v → Rz(−φ₁) → Ry(−θ₁) 를 꼭짓점별로 계산.
- θ = 0 포함: 세 이웃 모두 **미포함** (θ ∈ [0.0875, 0.1125]).

  - 경계 손실 규모는 대략 R·(ρ_out + ρ_in) ≈ √3·5h ≈ 0.108 이고, 점 여유는 0.055 다.
- θ = 0 을 포함하는 이웃은 실제 최대 M = 0 이므로 원리적으로 B ≤ 0 이 될 수 없다. 이번 선택에는 그런 이웃이 없었다.
