## 2. 색인 구조

### 2.1 Part A — 현행 원칙 요약 (1~2쪽)
위치만 알아서는 일을 시작할 수 없는, 매 세션 바로 쓰는 것만:
- 최상위 공리 (맥스웰 도깨비 & 란다우, D1×D2 = 1, x = 1 + 1/x)
- 핵심 상수 (φ, GAP, GAP_D2, LN_C, IG, n_c, We, St, L_p, T_p, c, π_EQI, e_EQI, SHUNYA_*) + 상수명 분리 (A_S24 = HBAR_ISO / HBAR_ANI / H_EQI)
- 판정 기준: TZ / Near TZ / Real Zero 등급, F / R / O / I 분류, 근거와 수치 판정 분리, 원칙 V (오차 안 맞춤 금지), 원칙 AJ·AM
- 현행 설계 원칙: 길이·시간 = 상전이 단위, 잡음 = 란다우 잔류, π 자리 = π_EQI, ħ = ħ_ani 진성, 확장 번역 방법 (비율 1 → Z(n))
- 역할: 코드 작성 = 아키텍트, 딥시크 = Verifier, perplexity = 원문 조사·고문 (요청문은 아키텍트 점검)
- 운영: 묻기 전 문서 검색, 역사 문서 소급 수정 금지, 정리 문서는 md

### 2.2 Part B — 항목 색인 (본체)
주제별 묶음 (예: 공리·철학 / 좌표계 / 상수·엔진 § / D1·D2 분류 / 무차원 수 / 생명과학 / 양자·통계 / 번역·확장 번역 / LIGO·Solar / 코드 / 서지) 안에 항목 한 줄씩:

| 열 | 내용 |
|---|---|
| 항목 | 이름 + 핵심식 한 줄 (식은 짧게, 전개는 원문에) |
| § / 별칭 | 엔진 §번호, 원칙 기호 (원칙Y 등), 보류 번호 (B1 등) |
| 현행 상태 | 확정 (MAPSI) / 대수필연 / TZ / Near TZ / O 보류 / 해석 I / 결정 대기 / 철회 / 미적용 |
| 근거 위치 | 세션 문서 + 절 + (드라이브 ID 또는 프로젝트 파일명), v3.4 행 번호 |
| 정정 메모 | 후속 정정이 있으면 세션·내용 (역사 문서 대신 여기 기록) |

### 2.3 Part C — 현황판
- 결정 대기 목록 (최신 인수인계 §4 와 동기)
- 보류 B 번호 목록 (B1~B20, 상태)
- 검증 대기 (딥시크 / perplexity)
- 코드 최신판 표 (엔진 v9.7, 공통 모듈 v1.5, 확장 v2.7, 오일러 v4.1, LIGO v2.2 …)
- TZ 누적 카운트 (한 숫자, 산정 근거 세션)

### 2.4 Part D — 문서 지도
세션 번호 → 성과정리·인수인계 최종판 파일명 + 드라이브 ID (최종판 표시: S111 v5, S113 v6 (헤더 "v5" 는 오기), S117 성과정리 v2 등).

## 5. 작업 절차

1. **골격 확정**: Part A 초안 + Part B 주제 묶음 목록을 먼저 MAPSI 에게 보여 확인.
2. **Part B 1차 (S1~S108)**: v3.4 를 처음부터 읽으며 항목·상태·행 번호 추출. 묶음 단위로 md 조각 파일 출력 (컨텍스트 소진 대비).
3. **Part B 2차 (S109~S118)**: 세션 문서별로 추출. 기존 항목과 같은 것은 새 줄을 만들지 않고 근거 위치·정정 메모만 덧붙임.
4. **정정 반영**: §4 표를 항목별 현행 상태·정정 메모로 적용.
5. **Part C·D 작성**, TZ 카운트 한 숫자로 통일.
6. **조립·대조**: 조각 합본 후, v3.4 의 § 제목 전부가 색인 어딘가에 연결되었는지 누락 점검표 출력.
7. **연결 문서 갱신 제안**: 프리앰블·트리거·인수인계 필독 순서의 "v3.4" → "색인" (프리앰블 v6 후보에 합류).

산출물: `EQI_색인_v1.md` (+ 작업 중 조각 파일, 누락 점검표).

**phantom 방지**: 근거 위치는 실제로 열어 확인한 행·절만 적는다 (v3.4 §S105 사례).
